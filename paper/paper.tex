\begin{abstract}
In heuristic symbolic search, a heuristic has two coupled effects: it changes
the states reached by the search and splits each binary decision diagram (BDD)
frontier into value buckets.
Cofactor profiles and decision-diagram width bound the second effect, but they
count residual combinations without recording which heuristic values remain
reachable from each decision node.
We define and study \emph{terminal incidence}, the number of pairs between
inner nodes and reachable active heuristic terminals in the algebraic decision
diagram (ADD) after masking it by a fixed frontier.
For the exact bucket-node sum $E$ of partitioning that frontier, we prove
$E\leq I$ and place $I$ below cofactor-, width- and Apply-based certificates.
An explicit decision-diagram family separates $I$ from all seven certificate
baselines by a factor $\Theta(k)$, and an exact-PDB witness shows that the
missing relation can decide a strict partition-effort order on a planning
frontier.
Terminal relabeling, including safe heuristic caps, cannot increase terminal
incidence, although it can increase exact partition effort.
We use these results to define an incidence-guided pattern-database selector.
A fresh-instance confirmation within previously studied families tests whether incidence ranks exact
fixed-frontier partition effort better than masked ADD size, active-value count
and seven certificate baselines; only success authorizes two complementary
end-to-end tests on the same frozen guided cohort, including a controlled
ablation against an otherwise identical selector guided by the developmental
predecessor $mJ$, which multiplies the co-occurring residual profile by the
active-value count.

\section{Introduction}

Symbolic search can apply one operation to a set of states represented by a
binary decision diagram (BDD)
\citep{bryant-ieeecomp1986,mcmillan-1993,edelkamp-helmert-ecp1999}.
This representation is often compact enough to replace many explicit
expansions by one symbolic image.
However, a BDD for a subset can be larger than the BDD for its superset.
The number of states and the size of their representation are therefore
different search resources.

Heuristics expose this distinction.
In explicit \astar, a heuristic changes which individual states are expanded
\citep{hart-et-al-ieeessc1968,pearl-1984}.
Product-at-evaluation symbolic \astar additionally partitions a frontier into
one BDD for each heuristic value \citep{edelkamp-reffel-ki1998}.
An informative heuristic can reduce the search space while making the
remaining frontiers harder to represent.
Even \hstar can cause exponentially more cumulative BDD nodes than blind
search \citep{speck-et-al-icaps2020}, and blind symbolic search remains a
strong cost-optimal method \citep{speck-et-al-jair2025}.
Explaining heuristic performance therefore requires separating at least a
search-space term and a representation term.
The exponential example conflates these terms: the heuristic changes which
frontiers arise and then partitions each resulting frontier.
We isolate the second effect by comparing heuristics on common fixed
frontiers before asking whether controlling it helps complete search.

Existing representation certificates count complete node--value rectangles
or combinations of state-set and heuristic residuals.
They are safe upper bounds, but they discard which values are actually
reachable from each decision node after restriction to the frontier.
Terminal substitution, per-value BDD forests and reachable-terminal sets of
individual MTBDD nodes are established
\citep{torralba-phd2015,ciardo-miner-jva2023,
duret-lutz-et-al-ciaa2025}.
We aggregate these reachable-terminal sets after frontier masking and connect
them to the
rootwise sum of value-bucket BDD sizes.

We capture this relation with \emph{terminal incidence}.
For a state set $S$ and heuristic $h$, we mask the ordered algebraic decision
diagram (ADD) for $h$ with $S$ and give all assignments outside $S$ a fresh
bottom terminal.
Terminal incidence $I$ counts an inner node once for every active nonbottom
terminal reachable from that node.
Each inner node of the BDD for one value bucket can be charged to one such
node--terminal pair, so the exact partition effort $E$ is at most $I$.

The resulting hierarchy explains why the earlier quantities can be loose.
The product $kD$ of active terminals and masked ADD nodes fills the complete
$k$-by-$D$ rectangle, while $I$ counts only its realized entries.
Replacing masked ADD nodes by masked cofactors, then by co-occurring pairs,
Cartesian pairs and width yields successively coarser certificates.
An independent standard-Apply argument gives a total-ADD certificate.
We prove that this certificate and the masked-cofactor certificate are
incomparable.
More strongly, one explicit decision-diagram family has exact counts
$E=I=k(r+L)$ for $k=2^r$, while each fixed certificate baseline is
$\Theta(k^2L)$ when $L\geq r$.
On an exact-PDB blind layer, two PDBs tie under active-value count, masked ADD
size and every certificate baseline, whereas incidence recovers their strict
exact-effort order.

The hierarchy makes incidence a safe certificate; it does not make incidence
an ordinal predictor across heuristics.
We test that separate claim empirically.
For heuristic design, incidence also has a closure property that exact effort
lacks.
Mapping ADD terminals through a cap can only merge residuals, decision nodes
and node--terminal pairs on a fixed frontier.
Exact partition effort need not decrease because merging two buckets replaces
two BDDs by a BDD for their union.
Incidence can therefore impose a budget that remains valid under further
caps; using exact effort would require materializing every value bucket and
would not provide this closure.
Conventional automatic PDB selection spends an abstract-state or construction
budget while optimizing heuristic information.
Our selector keeps a frozen candidate pool and information score, measures the
candidates on a short blind probe and adds a probe-conditioned representation
budget derived from a fixed cap-aware reference.

The paper thus makes three linked contributions.
First, it defines terminal incidence, proves the two-branch certificate
hierarchy, terminal-map contraction and separations, and gives the exact PDB
witness.
Second, Confirmation A tests whether $I$ ranks exact partition effort better
than masked ADD size, active-value count and seven certificate baselines on
common frontiers.
Third, only a successful confirmation authorizes fresh guided runs: a
controlled predecessor ablation changes whether $I$ or the developmental
co-occurring-profile certificate $mJ$ determines the selected candidate, while
Confirmation B compares the incidence-guided selector with the cap-aware
reference, a matched-work control and existing alternatives.
The two guided studies execute different cells on the same frozen B task
cohort and provide complementary tests rather than independent replications.
This staging prevents the selector from validating its own predictor.

\section{Fixed-Frontier Partitioning}
\label{sec-fixed-frontier}

We use finite deterministic SAS$^{+}$ planning tasks
$\task=\langle\vars,\ops,\sinit,\sgoal\rangle$
\citep{backstrom-nebel-compint1995} with positive integer operator costs.
The heuristic $h\colon\states\to\mathbb Z_{\geq0}\cup\{\infty\}$ is given a
fixed total extension to the Boolean state encoding.
Fix a Boolean variable order $\pi=(x_1,\ldots,x_n)$ and disable dynamic
reordering.
State sets use reduced ordered BDDs with complemented edges, and
$\bddsize{S}$ counts regular inner nodes as in CUDD.
Heuristics use reduced ordered ADDs under the same order.
For the PDBs below, the total ADD maps unused encoding assignments to zero and
uses a distinct terminal for abstract dead ends.

Let $\chi_S$ denote the characteristic function of $S$.
For a function $f$ and a prefix $\rho\in\{0,1\}^i$, let $f|_\rho$ be its
residual function and $\sub{i}{f}$ the set of distinct residuals at cut $i$.
We write
\[
\begin{aligned}
 \cutcount{i}{f}&=|\sub{i}{f}|,\\
 \cofcount(f)&=\sum_{i=0}^{n-1}\cutcount{i}{f},\\
 \width_\pi(f)&=\max_{0\leq i\leq n}\cutcount{i}{f}.
\end{aligned}
\]
For $S$ and $h$, the co-occurring profile is
\[
 \jointprofile{S}{h}=\sum_{i=0}^{n-1}
 \left|\{(\chi_S|_\rho,h|_\rho):\rho\in\{0,1\}^i\}\right|.
\]
Its Cartesian relaxation is
\[
 \cutprod{S}{h}=\sum_{i<n}\cutcount{i}{\chi_S}\cutcount{i}{h}.
\]

\begin{definition}[exact partition effort]
Let $S\ne\emptyset$, let $\terminalset{S}=h(S)$ be its active heuristic
values and let $k=|\terminalset{S}|$.
The exact fixed-frontier partition effort is
\[
 \partcost{S}{h}=\sum_{v\in\terminalset{S}}
 \bddsize{S\cap h^{-1}(v)}.
\]
\end{definition}

The active set includes $\infty$ when $h$ attains it on $S$ and excludes the
fresh masking terminal $\bot$ introduced below.

We use \emph{heuristic fragmentation} for the replacement of one frontier by
these value buckets; $E$ is its unnormalized partition node sum.
Earlier developmental studies divided this sum by the BDD size of the unsplit
frontier.
That denominator is constant when heuristics are compared on the same $S$, so
the normalized and unnormalized pair orders agree; Confirmation A uses $E$.
The sum counts nodes reachable from each bucket root separately and can
therefore count a manager node shared by several roots more than once.
If $S$ is the frontier presented to a product-at-evaluation step, $E$ is the
exact rootwise node sum of the complete terminal-class partition before an
infinite dead-end class, when present, is discarded and before any later
search operation changes the finite buckets.
Summing $E$ over common blind layers therefore gives a controlled measure of
the partitioning effect.
It does not measure how $h$ changes those layers in guided search, how long
buckets remain resident or the cost of heuristic construction, evaluation
and symbolic image operations.

Introduce a fresh terminal $\bot$ and define the \emph{masked heuristic}
\[
 \maskfun{S}{h}(x)=
 \begin{cases}
   h(x),&x\in S,\\
   \bot,&x\notin S.
 \end{cases}
\]
Let $M$ be its reduced ADD and let $D=\maskednodes{S}{h}$ be the number of
regular inner nodes of $M$.
For an inner node $u$ of $M$, let $T_M(u)\subseteq\terminalset{S}$ contain
the active nonbottom terminals reachable from $u$.
Thus $T_M(u)$ includes $\infty$ when it is reachable and never includes
$\bot$.

\begin{definition}[terminal incidence]
The \emph{terminal incidence} of $h$ on $S$ under $\pi$ is
\[
 \incidence{S}{h}=\sum_{u\in\mathrm{inner}(M)}|T_M(u)|.
\]
\end{definition}

Figure~\ref{fig-incidence} shows the distinction from $kD$.
The product counts the complete node--terminal rectangle, whereas incidence
counts the marked reachable pairs.
Each column also identifies the ADD nodes available to the corresponding
value bucket before Boolean reduction.
We compute $I$ exactly by building the masked ADD's reverse edges and running
a marked ancestor traversal from every active terminal; each visited inner
node contributes one incidence.
This takes $O(kD)$ time in the worst case and $O(D+k)$ auxiliary space.

\section{Certificate Hierarchy}
\label{sec-hierarchy}

The masked ADD is the common object behind the exact target and the new
predictor.
The cofactor and Apply certificate baselines result from forgetting different
parts of this object.

\begin{theorem}[two-branch fixed-frontier certificate]
\label{thm-incidence-hierarchy}
For every nonempty $S\subseteq\{0,1\}^n$ and total heuristic $h$,
\[
\begin{aligned}
 D
 &\leq \incidence{S}{h},\\
 \partcost{S}{h}
 &\leq \incidence{S}{h}
 \leq kD
 \leq k\cofcount(\maskfun{S}{h})
 \leq k\jointprofile{S}{h}\\
 &\leq k\cutprod{S}{h}
 \leq k\width_\pi(h)\cofcount(\chi_S).
\end{aligned}
\tag{1}
\]
If $A=|\mathrm{ADD}_\pi(h)|$ and $b=\bddsize{S}$, independently
\[
 \partcost{S}{h}\leq\incidence{S}{h}
 \leq k\bigl(2(A+1)b+A\bigr).
\tag{2}
\]
\end{theorem}

\begin{proof}[Proof sketch]
Relabel the terminals of $M$ by one exactly at value $v$ and by zero
elsewhere.
Reduction produces the BDD of $S\cap h^{-1}(v)$ without creating a decision
node.
For each fixed $v$, every surviving node can therefore be charged injectively
to an ancestor of $v$ in $M$.
Summing these per-terminal injections counts a node once for each reachable
active terminal and proves $E\leq I$.
Every inner node reaches an active terminal, and no node reaches more than
$k$, which gives $D\leq I\leq kD$.
An inner ADD node is witnessed by a residual at its own cut.
Each masked residual is determined by a co-occurring pair
$(\chi_S|_\rho,h|_\rho)$, after which Cartesian and width are direct
relaxations.
For Equation~(2), standard Apply states for a fixed terminal $v$ pair at most
$2b$ signed state-set nodes with at most $A$ ancestors of $v$ and the terminal
itself, plus at most $A$ heuristic nodes reached after the state-set residual
becomes one.
The supplement gives the injections and all boundary cases.
\end{proof}

The relation $D\leq I$ does not make masked ADD size a certificate for $E$:
it implies neither $E\leq D$ nor a guaranteed ordinal $E$--$D$ order across
heuristics.
We include both $D$ and the active-value count \valuecount as non-certificate
baselines. They test whether node--terminal reachability improves on the row
and column counts of the incidence relation, respectively.

Table~\ref{tab-information-loss} names the quantities used in the experiments
and shows what each relaxation discards.
The developmental predecessor $mJ$ is a certificate, not the co-occurring
profile $\jointprofile{S}{h}$ itself: $J$ abbreviates this profile in the
legacy artifact name, and the multiplier $m$ is the layerwise active-value
count $k$.
At one frontier, $mJ=k\jointprofile{S}{h}$ assigns every active terminal to
every co-occurring pair.
Terminal incidence retains this missing node--terminal relation.
We selected $mJ$ from the developmental analysis and do not present it as a
field-wide consensus explanation.
The legacy artifact name $mQ$ uses the same multiplier $m=k$.
The legacy artifact key ADD denotes the standard-Apply certificate in
Equation~(2), not masked ADD size $D$ or total ADD size alone.

For several fixed frontiers $S_g$, we sum every layerwise quantity using its
own $k_g$.
Thus $I=\sum_g I_\pi(S_g,h)$ and
$kD=\sum_g k_gD_\pi(S_g,h)$, with analogous definitions for the other
certificate baselines, $D=\sum_gD_\pi(S_g,h)$ and
$\valuecount=\sum_g k_g$ for the two non-certificate baselines.
Writing $A=|\mathrm{ADD}_\pi(h)|$ and $b_g=\bddsize{S_g}$, the layerwise
Apply term is
$A_{\mathrm{Apply},g}=k_g\bigl(2(A+1)b_g+A\bigr)$.
Summing Theorem~\ref{thm-incidence-hierarchy} preserves both branches.
Their strongest direct combination is the layerwise meet
\[
 B_\wedge=\sum_g\min\{k_gD_\pi(S_g,h),
 A_{\mathrm{Apply},g}\},
\]
which is no larger than either summed branch and remains an upper bound on
$E$.
No extra multiplier by the number of values is applied to $I$.
The inequalities compare certificates for one heuristic; they do not order
two heuristics by exact partition effort.
In particular, $\incidence{S}{h_1}<\incidence{S}{h_2}$ and
$\partcost{S}{h_i}\leq\incidence{S}{h_i}$ imply no order between
$\partcost{S}{h_1}$ and $\partcost{S}{h_2}$.
Confirmation A tests this separate ordinal question empirically.
The missing relation matters even for exact PDBs.
On one seven-bit task, the complete blind layer at $g=3$ is a fixed frontier
on which two PDBs have
$(E,I)=(10,10)$ and $(11,11)$, while all seven registered certificate baselines
tie:
the values for $kD$, $mQ$, $mJ$, Cartesian, width, Apply and $B_\wedge$ are
respectively $12,60,81,81,117,33$ and $12$ for both PDBs.
Masked ADD size ties at $D=4$, and active-value count ties at
$\valuecount=3$.
Thus, among the ten ordering predictors, only incidence recovers the strict
partition-effort order in this example.
This existential witness does not make incidence a universally correct
ordinal predictor; the supplement gives the task and every diagram count.

\subsection{An Exact Separation}

The gap between incidence and the certificate baselines is not an artifact of
reduction constants.

\begin{theorem}[incidence separation]
\label{thm-incidence-separation}
Let $k=2^r$ and $L\geq r\geq1$.
There exist a set $S$ and a $k$-valued total function $h$ over $r+L$ variables
for which
\[
 \partcost{S}{h}=\incidence{S}{h}=k(r+L),
\]
while each of the certificate baselines $kD$, $mQ$, $mJ$, Cartesian, width,
Apply and $B_\wedge$ is
$\Theta(k^2L)$.
More precisely,
\[
\begin{aligned}
D&=kL+k-1,\\
\cofcount(\maskfun{S}{h})&=kL+k+L-2,\\
\jointprofile{S}{h}=\cutprod{S}{h}&=2kL-1,\\
\width_\pi(h)&=k,\qquad \cofcount(\chi_S)=r+2L-1,\\
A&=k-1,\qquad b=L.
\end{aligned}
\]
\end{theorem}

\begin{proof}[Construction]
Use $r$ address bits followed by $L$ data bits.
Let $S$ contain every address together with the single data assignment
$1^L$, and give the $k$ addresses distinct heuristic values.
The masked ADD is a complete address tree followed by one length-$L$
conjunction chain per address.
Every address level contributes $k$ incidences and every chain node
contributes one, so $I=k(r+L)$.
Each value bucket fixes one address and the data string $1^L$, giving a
length-$(r+L)$ BDD and the same exact total.
Counting residuals at the address cuts, at the first data cut and after a
zero has occurred gives the displayed values.
They also give $B_\wedge=kD$.
The supplement proves that reduction cannot merge any of the counted nodes.
\end{proof}

The masked-cofactor certificate $k\cofcount(\maskfun{S}{h})$ and the
standard-Apply certificate remain incomparable.
Parity combined with a modulo-three frontier has linear masked cofactor
profile and a quadratic Apply certificate.
Conversely, $h=x_1$ on $S=\{x_1=1\}$ has masked cofactor count $2n-1$ and
ADD certificate $5$.
We therefore compare both branches rather than selecting a favored
relaxation.

\subsection{Terminal Maps and Caps}

Let $\mathcal Y$ contain the terminal labels of $h$, and let $\mathcal Z$ be
an arbitrary output-label set.
A terminal map is a function $\phi\colon\mathcal Y\to\mathcal Z$ that may
merge values.
We extend it to a fresh masking terminal
$\bot\notin\mathcal Y\cup\mathcal Z$ by $\phi(\bot)=\bot$.
Applying $\phi$ to an ADD and reducing cannot create residuals or inner
nodes.
The node--terminal incidence matrix contracts in both dimensions: columns
merge, rows merge or disappear and no new reachability relation appears.

\begin{proposition}[fixed-frontier contraction]
\label{prop-incidence-contraction}
For fixed $S$ and $h'=\phi\circ h$, terminal mapping cannot increase the
active-terminal count, masked ADD nodes, masked cofactor count, terminal
incidence, co-occurring or Cartesian profiles, heuristic width or full
heuristic ADD size.
It consequently cannot increase any certificate in
Theorem~\ref{thm-incidence-hierarchy}.
Exact partition effort $\partcost{S}{h'}$ can nevertheless exceed
$\partcost{S}{h}$.
\end{proposition}

\begin{proof}[Proof sketch]
Terminal relabeling followed by reduction only merges residuals and decision
nodes.
Each surviving masked-ADD node can be assigned to a distinct old preimage
node, and its reachable terminals are images of terminals reachable from that
preimage.
This contracts incidence; the other quantities follow directly from their
residual definitions.
The supplement gives the full argument.
\end{proof}

The exception matters.
Under order $x_1,x_2,x_3,x_4$, let
$F=\neg x_1\wedge\neg x_3\wedge\neg x_4$ and
$G=\neg x_2\wedge\neg x_3\wedge x_4$.
The sets are disjoint and their BDDs have three nodes each, while
$F\cup G$ has seven.
Define a total heuristic with value one on $F$, value two on $G$ and zero
elsewhere.
It has partition effort six on $S=F\cup G$; applying the uniform cap
$\kappa=1$ increases it to seven.
The supplement gives the residual count, an admissible-consistent planning
embedding and the general contraction proof.

Uniform caps are safe terminal maps for admissible consistent heuristics.
For $\kappa\in\mathbb Z_{\geq0}$ and finite $h(s)$, let
$h_\kappa(s)=\min\{h(s),\kappa\}$ and preserve $h(s)=\infty$.
The cap preserves admissibility and consistency, and smaller caps contract
every fixed-frontier certificate.
Proposition~\ref{prop-incidence-contraction} does not claim that caps reduce
the exact partition effort of every frontier or the cost of a complete search.
The supplement proves the proposition, including the incidence contraction,
and verifies the seven-node union in the counterexample.

\section{Incidence-Guided PDB Selection}
\label{sec-selector}

Pattern databases (PDBs) map states to exact abstract goal distances
\citep{culberson-schaeffer-compint1998,edelkamp-ecp2001}.
Automatic pattern selection usually optimizes heuristic information under an
abstract-state or construction budget
\citep{haslum-et-al-aaai2007,rovner-et-al-icaps2019}.
Unlike those construction budgets, our representation budget is conditioned
on realized blind-probe frontiers; the candidate pool and information score
remain fixed.

The fixed candidate pool contains the empty pattern and normalized,
deduplicated patterns from the BDD-prefix, goal-prefix, goal-fill and seeded
counterexample-guided abstraction refinement (CEGAR) sources.
Every pattern has at most $100{,}000$ abstract states.
For each nonempty raw PDB, we materialize caps
$0,1,2,4,\ldots,256$ below its maximum finite value and the exact endpoint.
The mandatory empty pattern has one exact width-one candidate and makes every
width budget feasible.
These choices, together with the cap grid, $K=32$ reference and 16-layer
horizon, were fixed before A or B outcome access; the supplement records which
ones were inherited from developmental protocols.

The selector first records exactly the first 16 completed blind layers on a
positive-cost task.
Within the same pool, the cap-aware cofactor-width reference retains each
pattern's strongest candidate whose cofactor width is at most $K=32$, then
selects among the retained candidates with the information score defined below.
We measure every candidate's terminal incidence on the same probe layers.
The reference's summed incidence becomes the candidate budget, so the
reference itself remains feasible.
For each pattern, the selector retains its strongest cap or exact endpoint
within this budget, if one exists; a pattern with no feasible candidate is
omitted.
It then maximizes the frozen lexicographic information score: initial
dead-end recognition, initial value, mean finite value and abstract dead-end
fraction, followed by smaller cofactor width, fewer abstract states and the
deterministic pattern tie-breaker.

\begin{proposition}[probe safety]
Let $S_1,\ldots,S_\ell$ be nonempty fixed probe frontiers.
Let a finite candidate pool contain the reference $h_R$, and set
$B=\sum_g\incidence{S_g}{h_R}$.
The incidence-budgeted selection is feasible.
Every returned candidate $\hat h$ satisfies
$\sum_g\partcost{S_g}{\hat h}\leq B$.
Every terminal map of $\hat h$ also satisfies the incidence budget.
\end{proposition}

\begin{proof}
The reference is feasible by the definition of $B$.
Theorem~\ref{thm-incidence-hierarchy}, summed over the probe, gives
$\sum_g\partcost{S_g}{\hat h}
 \leq\sum_g\incidence{S_g}{\hat h}\leq B$;
Proposition~\ref{prop-incidence-contraction} gives the final claim.
\end{proof}

This rule spends the same measured representation budget differently from the
reference.
The proposition is an absolute probe partition-effort bound, not an ordinal
guarantee that a lower-incidence candidate has lower exact effort than another
candidate.
The selector is not an oracle: its probe consists only of the first 16
completed blind layers on a positive-cost task and does not use the exact
target $E$.
For every candidate and probe layer, computing $E$ would materialize and
reduce one BDD for each active value, whereas computing $I$ reuses the masked
ADD and its reverse-edge traversal.
A finite $E$-guided selector is nevertheless possible in principle.
The registered A diagnostics therefore compare measurement times and report
the exact-$E$ regret of each predictor's top choice.
Incidence additionally supplies closure that $E$ lacks: a further cap can
increase exact partition effort, while
Proposition~\ref{prop-incidence-contraction} guarantees that every terminal
map of an incidence-feasible candidate remains within the incidence budget.
A matched-work control performs the identical probe, pool construction,
candidate materialization and incidence measurement, then executes the fixed
reference.
The trace records the full candidate pool, cap identities, exact raw-value
histograms, per-layer incidences, both selections and resource accounting.
Independent replay rejects a trace if any pool, cap, score, monotonicity or
identity invariant fails.
Probe and selection CPU time, wall time and peak-memory deltas are recorded
separately as descriptive phase accounting.
The matched-work control matches the registered probe and candidate-measurement
work counts, while the
comparison with the standalone reference retains that work in end-to-end
planner time.

For a direct test of the metric, we also define a symmetric $mJ$-guided
selector.
On complete probes, all three arms measure both $I$ and $mJ$ on the same probe
and materialize the same candidates.
The incidence and $mJ$ arms derive separate budgets from the same standalone
$K=32$ reference, retain the strongest feasible cap of each pattern under
their respective metric and apply the same information score.
The matched arm has the same registered structural work counts and executes the
$K=32$ reference.
The only mode-specific choice is which precomputed winner becomes the final
heuristic; the two winners may coincide.

\section{Confirmatory Evaluation}
\label{sec-confirmation}

The evaluation separates ordinal prediction from algorithm evaluation.
Our original source census attempted translation of 1,640 unused benchmark candidates under
fixed resource limits, but only 396 tasks from 19 previously studied families
satisfied the planner's structural requirements.
This was insufficient for the original unseen-family design; no heuristic
performance was measured on those candidates.
We therefore test fresh generated instances within previously studied families,
using the PDDL generator collection of \citet{seipp-et-al-zenodo2022}.
A translation-only pilot determines the supported families before heuristic
outcomes are observed.
We fix size grids, seeds, duplicate exclusions, configurations and analysis
thresholds before the predictor runs.
Selector tasks are generated only if Confirmation A passes, using disjoint
seeds and problem inputs.
This design tests new instances of the retained families, not transfer to
unseen families; the supplement records the source audit and selection rules.

\subsection{Confirmation A: Does Incidence Rank Partition Effort?}

Confirmation A requires 650 source-attested tasks, balanced across the
structurally supported families and five fixed size levels per family.
Each task uses the BDD-prefix, goal-prefix, goal-fill and seeded CEGAR direct
PDB generators with exact values, a $100{,}000$-state budget and one fixed BDD
order.
We evaluate each heuristic on up to the first 16 completed non-goal blind
layers in increasing $g$ order without letting it affect the search.
A task solved earlier contributes the common complete pre-goal horizon, so all
four configurations use identical frontiers.

For each layer, exact partition effort $E$ is the target and $I$ is the primary
predictor.
We compare it with the non-certificate baselines $D$ and \valuecount and the
seven certificate baselines $kD$, $mQ$, $mJ$, Cartesian, width and the
standard-Apply quantity
stored under the legacy key ADD in Theorem~\ref{thm-incidence-hierarchy}, plus
their layerwise meet $B_\wedge$.
Together with $I$, these form ten ordering predictors.
Every logged layer must satisfy both certificate branches before it enters the
analysis.
Within each eligible task, the primary analysis retains every semantic-PDB
pair on which $E$ is strictly ordered.
For each predictor, a concordant pair scores one, a predictor tie scores one
half and a discordant pair scores zero.
These task concordances are averaged first within family and then with equal
family weight.
The former grand-shared set on which $E$ and all ten predictors are strictly
ordered is retained as a non-gating sensitivity analysis.

The complete gate requires at least 300 eligible and comparison tasks, at
least 25 eligible and comparison families and at least 600 target-strict
pairs.
The macro concordance of $I$ must reach 0.65 and exceed every baseline by at
least 0.02.
For each of the nine baselines, the lower endpoint of the 95\% paired-family
bootstrap
reweighting interval with $100{,}000$ replicates must be positive, and every
leave-one-family-out difference must be positive.
Failure of any support or effect clause is a failed confirmation.
The infeasible unseen-family stratum is not part of this within-family test.

\subsection{Controlled Predecessor Ablation: $I$ versus $mJ$}

This campaign is authorized only if Confirmation A passes.
The co-occurring-profile certificate $mJ$ is the developmental structural
predecessor of terminal incidence: it preserves which state and heuristic
residuals share a prefix, but its factor $k$ assigns every active value to
every pair.
It was selected for this ablation before Confirmation A and is not presented
as a field-wide consensus explanation.
It uses the frozen 300-task Confirmation B cohort, but executes fresh runs in
three task-blocked arms: incidence-guided, $mJ$-guided and matched $K=32$.
Within each family, arm order rotates deterministically by task.
On complete probes, every arm reconstructs both metrics, budgets, winners and
the complete candidate trace; normalized structural certificates must be
identical apart from timing, memory and the final-selection event.
If the blind state space yields fewer than 16 layers, all three arms must expose
the same certified three-event short-probe trace, exit
\texttt{SEARCH\_UNSUPPORTED} (34), record coverage zero and perform no
selection or fallback.
The symmetric triad remains in both full contrasts as PAR2 3600 in every arm
and supplies no winner; any asymmetry invalidates the campaign.

The primary contrast is incidence-guided minus $mJ$-guided.
PAR2 is total planner time for a solved run, which is at most 1800 seconds,
and 3600 seconds for every unsolved certified cell.
It passes only with nonlower coverage, an equal-family normalized PAR2
improvement of at least 0.02, a strictly positive lower endpoint of the 95\%
paired-family bootstrap interval and a positive effect after leaving out every
family.
The same clauses must hold on the prespecified subset of complete probes where
the two reconstructed winners differ, with at least 50 tasks from ten
families.
This subset is defined only by certified selector structure and is blind to
search coverage and runtime.
Incidence-guided versus matched $K=32$ is secondary and cannot change the
primary decision.
Each contrast also has a fixed non-gating decomposition: a paired table of
tasks solved by both arms, by only one arm or by neither, and the equal-family
mean total-time difference normalized by 1800 on commonly solved tasks.

A fixed non-gating trace panel reports complete/short support, winner uptake,
cap-versus-pattern changes, budget use, cross-metric retention, score
relations, structural work and selector overhead.
Complete triads contribute selector structure once per task, while short
triads contribute only support and probe overhead.
Because the trace contains neither exact $E$ nor a final-search bucket
trajectory, the panel cannot establish fragmentation mediation or affect the
registered decision.

\subsection{Confirmation B: Does Incidence Improve Selection?}

Confirmation B may be prepared only if Confirmation A passes its complete

Its target is a separate 300-task generated-instance cohort within the

\section{Related Work}

Product-at-evaluation \bddastar partitions frontiers by heuristic value
\citep{edelkamp-reffel-ki1998}, while SetA\ensuremath{^{*}} and \ghseta
partition transition relations \citep{jensen-et-al-aij2008}.
ADDA\ensuremath{^{*}} uses algebraic diagrams directly
\citep{hansen-et-al-sara2002}.
The exponential separation between \hstar and blind symbolic search
\citep{speck-et-al-icaps2020} establishes the problem but does not identify a
fixed-frontier ordinal predictor.

Residual width, cofactor profiles and Apply bounds are standard decision-
diagram tools \citep{wegener-2000,bryant-ieeecomp1986}.
Our cofactor analysis connects them to symbolic search and supplies reusable
worst-case guarantees.
The relation between one multi-terminal ADD and a forest of BDDs for its
values is classical \citep{bahar-et-al-iccad1993}.
In particular, terminal substitution bounds each value BDD by the size of the
ADD \citep[Proposition~2.1]{torralba-phd2015}; applied after masking and summed
over $k$ values, this gives the $E\leq kD$ certificate.
\citet{ciardo-miner-jva2023} explicitly compare an MTBDD with its shared
per-value BDD forest, whose unique-node size differs from our rootwise sum
$E$.
Reachable-terminal sets of individual MTBDD nodes are also used by
\citet{duret-lutz-et-al-ciaa2025}.
We aggregate these sets after frontier masking and refine the substitution
charge: a node is counted only for terminals reachable below it, giving
$E\leq I\leq kD$.
To our knowledge, this aggregate and charging bound have not previously been
used as a fixed-frontier fragmentation certificate in symbolic heuristic
search.
Theorem~\ref{thm-incidence-separation} shows that this relation can remove a
factor of order $k$, the number of active values, from all seven registered
certificate baselines.

PDB compression can merge entries or coarsen values
\citep{felner-et-al-jair2007,sturtevant-et-al-aaai2017}.
The uniform cap used here is not a new compression primitive.
Its role is to provide a certified nested candidate family whose incidence can
be measured under the same fixed probe.
Total ADD size is a separate representation budget, and the masked-cofactor
and standard-Apply certificates in
Theorem~\ref{thm-incidence-hierarchy} are incomparable.

\section{Limitations}

Terminal incidence concerns representation after both a frontier and a
variable order have been fixed.
It does not predict which states a heuristic causes the search to reach.
Its target is BDD-node partition effort rather than runtime or peak memory,
and it omits symbolic image operations, heuristic construction and evaluator
overhead.
The certificate is one-sided: small incidence bounds partition effort, but the
bound provides no converse.
A large incidence value alone neither certifies large reduced buckets nor
determines the ordinal ranking of two heuristics.

Confirmation A compares several PDBs on common blind frontiers.
It can establish an ordinal predictor of fixed-frontier partition effort within
that design, but it cannot establish a cause of overall heuristic performance.
Its generated tasks come from previously studied families and fixed size grids;
distinct input bytes do not exclude structurally isomorphic instances.
The controlled predecessor-ablation campaign changes only which precomputed winner
becomes the final heuristic, but reuses Confirmation B's task cohort and is
therefore not an independent task holdout from that broader evaluation.
The direct campaign supports only the $I$-versus-$mJ$ selection-rule contrast
and its secondary matched-$K=32$ comparison.
Confirmation B separately supports the broader comparison with the cap-aware
reference and alternative methods.
Even if Confirmation A, the direct campaign and Confirmation B all pass, the
conclusions remain specific to the frozen PDB pool, the first 16 completed
blind probe layers on positive-cost tasks, forward
product-at-evaluation search, the tested benchmarks and the fixed-order CUDD
representation.

The exact separation is a decision-diagram construction, not a claim that its
parameters describe typical planning tasks.
Caps contract every certificate on a fixed frontier but can increase exact
partition effort, as the four-variable counterexample shows.
Changing the heuristic may also change all later frontiers, so fixed-frontier
contraction does not imply monotone complete-search performance.

\section{Conclusions}

Terminal incidence measures the relation omitted by cofactor and width
baselines: which active heuristic terminals remain reachable from each inner
node of the masked ADD.
It upper-bounds exact fixed-frontier partition effort, lies below two
independent certificate branches and is sharper by a factor $\Theta(k)$ on an
exact decision-diagram family.
The theory also identifies a strict design boundary.
Terminal maps contract incidence, but neither exact partition effort nor a
complete symbolic search must improve.

The staged experiments respect that boundary.
Confirmation A tests terminal incidence only as an ordinal predictor of exact
partition effort on common frontiers.
Only if that claim survives do fresh guided runs test whether choosing with
incidence rather than $mJ$ improves search, and whether the
incidence-budgeted selector improves over the reference and alternatives.
