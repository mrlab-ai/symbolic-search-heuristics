\paragraph{Guide.}
The first part proves the terminal-incidence hierarchy, its exact separation,
fixed-frontier contraction, the counterexample for exact partition effort and
the incomparability of the masked-cofactor and standard-Apply certificates.
The next part archives the detailed cofactor, search-effort, pruning,
lower-bound and heuristic-family theory that led to the new metric; it is
developmental provenance rather than a second current contribution.
The final parts archive the developmental experiments, including negative
results, and expand the related-work comparison.

\section{Terminal Incidence on a Fixed Frontier}
\label{sec:supp-incidence}

Fix Boolean variables $x_1,\ldots,x_n$ in order $\pi$, and let $\chi_S$ denote
the characteristic function of $S$.
For a function $f$ and a prefix assignment $\rho\in\{0,1\}^i$, let
$f|_\rho$ be the residual function and let
$\sub{i}{f}=\{f|_\rho:\rho\in\{0,1\}^i\}$.
We write
\[
 \cutcount{i}{f}=|\sub{i}{f}|,
 \qquad
 \cofcount(f)=\sum_{i=0}^{n-1}\cutcount{i}{f},
 \qquad
 \width_\pi(f)=\max_{0\leq i\leq n}\cutcount{i}{f}.
\]
Boolean functions use reduced ordered BDDs with complemented edges, and
$\bddsize{f}$ counts regular inner nodes.
Finite-valued functions use reduced ordered ADDs without complemented edges;
$|\mathrm{ADD}_\pi(f)|$ also counts inner nodes.

Let $S\ne\emptyset$ be a set of Boolean assignments and let $h$ be a total
function on the Boolean cube with finitely many terminal labels, possibly
including $\infty$.
Write $\terminalset{S}=h(S)$ and $k=|\terminalset{S}|$.
The exact fixed-frontier partition effort is
\begin{equation}
 \partcost{S}{h}=\sum_{v\in\terminalset{S}}
 \bddsize{S\cap h^{-1}(v)}.
 \label{eq:supp-exact-partition}
\end{equation}
This is a sum of reachable regular nodes per bucket root.
The active set includes $\infty$ when attained on $S$.
If several roots share a manager node, the sum counts it once for each root;
it is not a claim about construction time, peak memory or the number of unique
manager nodes.
Introduce a fresh terminal $\bot\notin h(\{0,1\}^n)$ and define
\[
 \maskfun{S}{h}(x)=
 \begin{cases}
 h(x),&x\in S,\\
 \bot,&x\notin S.
 \end{cases}
\]
Let $M=\mathrm{ADD}_\pi(\maskfun{S}{h})$, let
$D=\maskednodes{S}{h}$ be its number of inner nodes and let
$T_M(u)\subseteq\terminalset{S}$ be the active terminals reachable from an
inner node $u$ of $M$.
The fresh terminal $\bot$ is never active, whereas $\infty$ is active whenever
it is attained on $S$.
Per-node reachable-terminal sets themselves are established MTBDD operations
\citep{duret-lutz-et-al-ciaa2025}; terminal incidence aggregates their
cardinalities after frontier masking.
Terminal incidence is
\begin{equation}
 \incidence{S}{h}=\sum_{u\in\mathrm{Inn}(M)}|T_M(u)|.
 \label{eq:supp-terminal-incidence}
\end{equation}
The implementation enumerates $M$ once, stores reverse edges and performs a
marked ancestor traversal from each active terminal.
Every visited inner node contributes one to Equation
\ref{eq:supp-terminal-incidence}.
Given $M$, this uses $O(kD)$ time in the worst case and $O(D+k)$ auxiliary
space; masked-ADD construction is timed separately.
Finally, define
\[
 \jointcount{i}{S}{h}=
 \left|\{(\chi_S|_\rho,h|_\rho):\rho\in\{0,1\}^i\}\right|,
 \qquad
 \jointprofile{S}{h}=\sum_{i=0}^{n-1}\jointcount{i}{S}{h},
\]
and
\[
 \cutprod{S}{h}=\sum_{i=0}^{n-1}
 \cutcount{i}{\chi_S}\cutcount{i}{h}.
\]

\subsection{Exact Target and the Cofactor Branch}

\begin{lemma}[terminal charging]
\label{lem:supp-terminal-charging}
For every active terminal $v\in\terminalset{S}$, the regular inner nodes of
the BDD for $S\cap h^{-1}(v)$ inject into the inner nodes of $M$ from which
$v$ is reachable.
Consequently, $\partcost{S}{h}\leq\incidence{S}{h}$.
\end{lemma}

\begin{proof}
The classical terminal-substitution construction produces each Boolean value
set by relabeling and reducing the ADD
\citep[Proposition~2.1]{torralba-phd2015}.
We refine its whole-diagram charge by retaining only ancestors of the selected
terminal.
Relabel terminal $v$ of $M$ by one and every other terminal, including
$\bot$, by zero.
The resulting ordered Boolean diagram represents
$S\cap h^{-1}(v)$.
Each relabeled source residual reduces to a signed BDD pointer; charge it to
the pointer's regular node whenever that pointer is nonterminal.
Reduction removes nodes whose children agree, merges isomorphic nodes and
uses complemented pointers to share complementary residuals, but it does not
create a decision node with no source node in $M$.
Partition the source decision nodes by the regular BDD node, if any, to which
their relabeled residual is charged.
Choose one source node for every regular node of the reduced bucket BDD.
The chosen nodes are distinct because the source classes are disjoint.
Moreover, a chosen source node reaches $v$: otherwise every terminal below it
would be relabeled zero and its Boolean residual would be constant, so it
could not represent a regular BDD node.
This gives the claimed injection for $v$.
Summing its cardinality over all active terminals counts every source node
$u$ exactly $|T_M(u)|$ times and proves
$\partcost{S}{h}\leq\incidence{S}{h}$.
\end{proof}

\begin{lemma}[masked residuals]
\label{lem:supp-masked-residuals}
The masked ADD and its cofactor profile satisfy
\[
 D\leq\cofcount(\maskfun{S}{h})\leq\jointprofile{S}{h}.
\]
\end{lemma}

\begin{proof}
Every inner node of $M$ labeled $x_{i+1}$ is reached by some prefix of length
$i$ and computes a distinct masked residual at that cut.
Mapping the node to such a residual injects the inner nodes into the disjoint
union of the cut profiles, so $D\leq\cofcount(\maskfun{S}{h})$.

For the second inequality, fix a cut $i$.
The pair $(\chi_S|_\rho,h|_\rho)$ determines the masked residual because, for
every suffix $\sigma$,
\[
 \maskfun{S}{h}|_\rho(\sigma)=
 \begin{cases}
 h|_\rho(\sigma),&\chi_S|_\rho(\sigma)=1,\\
 \bot,&\chi_S|_\rho(\sigma)=0.
 \end{cases}
\]
Thus the map from realized residual pairs to masked residuals is surjective,
which gives
$\cutcount{i}{\maskfun{S}{h}}\leq\jointcount{i}{S}{h}$.
Summing over $i<n$ proves the claim.
\end{proof}

\begin{theorem}[two-branch fixed-frontier certificate]
\label{thm:supp-incidence-hierarchy}
For every nonempty $S$ and total $h$,
\begin{equation}
\begin{aligned}
 D
 &\leq\incidence{S}{h},\\
 \partcost{S}{h}
 &\leq\incidence{S}{h}
 \leq kD
 \leq k\cofcount(\maskfun{S}{h})
 \leq k\jointprofile{S}{h}\\
 &\leq k\cutprod{S}{h}
 \leq k\width_\pi(h)\cofcount(\chi_S).
\end{aligned}
\label{eq:supp-cofactor-chain}
\end{equation}
If $A=|\mathrm{ADD}_\pi(h)|$ and $b=\bddsize{S}$, then independently
\begin{equation}
 \partcost{S}{h}\leq\incidence{S}{h}
 \leq k\bigl(2(A+1)b+A\bigr).
 \label{eq:supp-add-branch}
\end{equation}
\end{theorem}

\begin{proof}
Lemma~\ref{lem:supp-terminal-charging} gives the first inequality beginning
with $\partcost{S}{h}$.
Every inner node of a reduced masked ADD computes a nonconstant function.
It therefore reaches at least one nonbottom terminal, since a subgraph that
reached only $\bot$ would reduce to that terminal.
This proves $D\leq\incidence{S}{h}$.
No inner node reaches more than all $k$ active terminals, so
$\incidence{S}{h}\leq kD$.
Lemma~\ref{lem:supp-masked-residuals} proves the next two inequalities.
At cut $i$, the realized pairs counted by $\jointcount{i}{S}{h}$ form a
subset of
$\sub{i}{\chi_S}\times\sub{i}{h}$.
Hence
\[
 \jointcount{i}{S}{h}
 \leq\cutcount{i}{\chi_S}\cutcount{i}{h}
 \leq\cutcount{i}{\chi_S}\width_\pi(h).
\]
Multiplying by $k$ and summing proves the remainder of
Equation~\ref{eq:supp-cofactor-chain}.

It remains to prove the ADD branch.
Fix an active terminal $v$ and consider only nodes of $M$ from which $v$ is
reachable.
The standard recursive construction of
$\mathrm{ITE}(\chi_S,h,\bot)$ associates every such decision node with a
state-set residual and a heuristic residual.
A regular state-set node yields at most two signed residuals because of
complemented edges, so there are at most $2b$ nonconstant state-set
residuals.
For fixed $v$, the heuristic residual must be an inner ADD node from which
$v$ is reachable or terminal $v$ itself, giving at most $A+1$ choices.
These pairs account for at most $2b(A+1)$ decision nodes.
Once the state-set residual is the one-terminal, the result follows $h$
directly and contributes at most its $A$ inner nodes; the zero-terminal
contributes none.
Reduction can only delete or merge these recursive states.
Therefore at most $2(A+1)b+A$ inner nodes of $M$ can reach $v$.
Summing over the $k$ active terminals gives
Equation~\ref{eq:supp-add-branch}.
\end{proof}

The masked-cofactor and standard-Apply certificates deliberately share only
the exact target and terminal incidence.
In particular, Theorem~\ref{thm:supp-incidence-hierarchy} does not order the
masked cofactor and ADD certificates.

\subsection{Aggregation Across Fixed Frontiers}

Let $G$ be any finite set of layer indices and let $S_g$ be a nonempty fixed
frontier for every $g\in G$.
Write $k_g=|h(S_g)|$, $D_g=\maskednodes{S_g}{h}$ and
$m_g=\maskfun{S_g}{h}$.
The run-level target and predictors used in the confirmatory study are
\[
\begin{array}{@{}rcl@{\qquad}rcl@{}}
E&=&\displaystyle\sum_{g\in G}\partcost{S_g}{h},
&I&=&\displaystyle\sum_{g\in G}\incidence{S_g}{h},\\[3pt]
D&=&\displaystyle\sum_{g\in G}D_g,
&\valuecount&=&\displaystyle\sum_{g\in G}k_g,\\[3pt]
kD&=&\displaystyle\sum_{g\in G}k_gD_g,
&mQ&=&\displaystyle\sum_{g\in G}k_g\cofcount(m_g),\\[3pt]
mJ&=&\displaystyle\sum_{g\in G}k_g\jointprofile{S_g}{h},
&C&=&\displaystyle\sum_{g\in G}k_g\cutprod{S_g}{h},\\[3pt]
W&=&\displaystyle\sum_{g\in G}k_g\width_\pi(h)\cofcount(\chi_{S_g}),
&A_{\mathrm{Apply}}&=&\displaystyle\sum_{g\in G}
k_g\bigl(2(A+1)\bddsize{S_g}+A\bigr).
\end{array}
\]
Here $J$ in the legacy name $mJ$ abbreviates the co-occurring residual profile,
while $m$ denotes multiplication by the layerwise active-value count $k_g$.
Thus $mJ$ is a certificate score rather than the profile itself.
The strongest direct combination of the two certificate branches is their
layerwise meet
\[
 B_\wedge
 =\sum_{g\in G}\min\bigl\{k_gD_g,
 k_g\bigl(2(A+1)\bddsize{S_g}+A\bigr)\bigr\}.
\]
Summing the nonnegative layerwise inequalities gives
\[
 E\leq I\leq kD\leq mQ\leq mJ\leq C\leq W,
 \qquad
 E\leq I\leq A_{\mathrm{Apply}},
 \qquad
 E\leq I\leq B_\wedge\leq\min\{kD,A_{\mathrm{Apply}}\}.
\]
The definition of $I$ already sums over terminals through
Equation~\ref{eq:supp-terminal-incidence}; multiplying it by $k_g$ again would
double-count the value partition.
Masked ADD size $D$ and active-value count \valuecount are non-certificate
ordering baselines. They are the row and column counts of the node--terminal
incidence relation. The relation $D\leq I$ does not imply $E\leq D$, and
neither baseline supplies a guaranteed order for $E$ across two heuristics.

\subsection{An Ordinal Separation for Exact PDBs}

The certificate inequalities do not imply an order between two heuristics.
The next example isolates the node--terminal relation: every fixed
relaxation ties, while incidence recovers a strict exact order.

\begin{example}[PDB ordinal separation]
\label{ex:supp-pdb-ordinal-separation}
Consider Boolean variables $z,a_1,a_2,a_3,b_1,b_2,b_3$.
Initially $z=0$ and all six $a$- and $b$-variables are one.
The partial goal is $z=0$ and $a_1=b_1=b_2=0$; variables
$a_2,a_3,b_3$ are unconstrained.
For every assignment
$\sigma\in\{0,1\}^{\{a_1,a_2,a_3,b_1,b_2,b_3\}}$, one initialization
operator has precondition $z=0$, cost 3 and the effect $z:=1$ together with
$(a_1,a_2,a_3,b_1,b_2,b_3):=\sigma$.
These are 64 distinct operators.
The following six distance-defining operators have the additional precondition
$z=1$, and every unmentioned variable is unchanged:
\begin{center}
\begin{tabular}{@{}lll@{}}
\toprule
Remaining precondition & Effect & Cost\\
\midrule
$a_1=1$ & $a_1:=0$ & 2\\
$a_1=1,a_2=0$ & $a_1:=0$ & 1\\
$a_1=1,a_3=0$ & $a_1:=0$ & 1\\
$b_1=1$ & $b_1:=0,b_2:=0$ & 1\\
$b_2=1$ & $b_2:=0$ & 2\\
$b_2=1,b_3=0$ & $b_2:=0$ & 1\\
\bottomrule
\end{tabular}
\end{center}
Finally, a finish operator with precondition
$z=1,a_1=b_1=b_2=0$ sets $z:=0$ at cost 1.

The only actions applicable initially are the 64 cost-3 initialization
operators.
Their successors are exactly all assignments with $z=1$, so
$S=\{z=1\}$ is the complete non-goal blind layer at $g=3$.
The finish operator reaches a goal at cost 4, and no goal is reachable earlier.
The exact PDBs for $P_A=\{a_1,a_2,a_3\}$ and
$P_B=\{b_1,b_2,b_3\}$, written in lexicographic abstract-state order, are
\[
 h_A=(0,0,0,0,1,1,1,2),
 \qquad
 h_B=(0,0,1,2,1,1,1,1).
\]
Projecting away $z$ leaves the six distance-defining transitions unchanged.
The initialization operators cost 3 and therefore cannot improve displayed
distances of at most 2; the finish operator and operators on the other pattern
project to positive-cost self-loops.

Use order $(z,a_1,b_1,b_2,a_2,a_3,b_3)$ on this blind frontier.
Before masking by $S$, both heuristic ADDs have three inner nodes.
For $h_A$, their active-terminal reach-set sizes are $(3,2,2)$; for $h_B$
they are $(3,3,2)$.
Masking adds one leading $z$ node with three reachable active terminals.
Consequently $D_A=D_B=4$ and
$N_{\mathrm{val},A}=N_{\mathrm{val},B}=3$, while $I_A=10$ and $I_B=11$.

The three value-bucket BDDs have sizes $(2,4,4)$ for $h_A$ and $(3,4,4)$
for $h_B$ under complemented edges.
Hence $(E_A,I_A)=(10,10)$ and $(E_B,I_B)=(11,11)$.
Nevertheless, both masked ADDs have cofactor sum 20, both co-occurring and
Cartesian profiles sum to 27, both heuristic widths are three,
$\cofcount(\chi_S)=13$, and $\bddsize{S}=1$.
With three active values and three inner nodes in each unmasked heuristic ADD,
all seven certificate baselines therefore tie:
\[
 (kD,mQ,mJ,C,W,A_{\mathrm{Apply}},B_\wedge)
 =(12,60,81,81,117,33,12).
\]
Among the ten ordering predictors, only incidence distinguishes the two
exact partition efforts.
\end{example}

The example is an ordinal separation, not a universal correctness result for
incidence.
It shows that the node--terminal relation discarded by every fixed
certificate relaxation can be decisive on an actual blind layer even when
their aggregate values all agree.

\subsection{Exact Separation from All Relaxations}

\begin{theorem}[exact incidence separation]
\label{thm:supp-incidence-separation}
For every $k=2^r$ and $L\geq r\geq1$, there are $S$ and a $k$-valued total
function $h$ over $r+L$ variables for which
\[
 \partcost{S}{h}=\incidence{S}{h}=k(r+L).
\]
The remaining quantities are exactly
\[
\begin{array}{@{}rcl@{\qquad}rcl@{}}
D&=&kL+k-1,
&\cofcount(\maskfun{S}{h})&=&kL+k+L-2,\\
\jointprofile{S}{h}&=&2kL-1,
&\cutprod{S}{h}&=&2kL-1,\\
\width_\pi(h)&=&k,
&\cofcount(\chi_S)&=&r+2L-1,\\
A&=&k-1,
&b&=&L.
\end{array}
\]
Consequently, $B_\wedge=kD$, and each of $kD$, $mQ$, $mJ$, Cartesian, width,
Apply and $B_\wedge$ is $\Theta(k^2L)$, while $E=I=\Theta(kL)$.
\end{theorem}

\begin{proof}
Use address bits $a_1,\ldots,a_r$ followed by data bits
$z_1,\ldots,z_L$ in this order.
Every address $a\in\{0,1\}^r$ names a distinct terminal $v_a$.
Define
\[
 S=\{(a,z):z_1=\cdots=z_L=1\},
 \qquad
 h(a,z)=v_a.
\]
Thus $S$ contains all $k$ addresses but only data string $1^L$.

The masked ADD first distinguishes all addresses.
No two address residuals can merge because they reach disjoint nonbottom
terminal sets, so this prefix is a complete binary tree with $k-1$ inner
nodes.
Below address $a$, the masked residual returns $v_a$ exactly on $1^L$ and
$\bot$ otherwise.
It is a chain of $L$ nodes.
Chains for different addresses cannot share a node because their unique
nonbottom terminals differ.
Therefore
\[
 D=(k-1)+kL=kL+k-1.
\]

At every one of the $r$ address levels, the reachable-terminal counts of all
nodes sum to $k$: at depth $d$ there are $2^d$ nodes, each reaching
$k/2^d$ active terminals.
Every node of every data chain reaches its one terminal $v_a$.
Hence
\[
 \incidence{S}{h}=kr+kL=k(r+L).
\]
The bucket for $v_a$ is the singleton assignment $(a,1^L)$.
Its reduced BDD has exactly one node for every address and data variable,
since each variable remains essential along the unique satisfying path.
It therefore has $r+L$ regular inner nodes even with complemented edges.
Summing over all addresses proves
$\partcost{S}{h}=k(r+L)=\incidence{S}{h}$.

We next count residuals.
Before all address bits are read, cut $i<r$ has exactly $2^i$ masked
residuals.
At cut $r$, the $k$ addresses give $k$ different data chains.
At cut $r+j$ for $1\leq j<L$, a prefix containing a zero gives the bottom
residual, while the all-one prefix leaves one distinct chain for each
address.
Thus
\[
 \cofcount(\maskfun{S}{h})
 =\sum_{i=0}^{r-1}2^i+k+(L-1)(k+1)
 =kL+k+L-2.
\]

For the joint profile, the state-set residual is the same data conjunction
at every address cut, while the heuristic residuals distinguish the
$2^i$ address prefixes.
Cut $r$ gives $k$ pairs.
After at least one data bit, each address occurs once with state residual zero
and once with the residual conjunction from the all-one prefix, giving $2k$
pairs.
Therefore
\[
 \jointprofile{S}{h}
 =\sum_{i=0}^{r-1}2^i+k+(L-1)2k=2kL-1.
\]
At the same cuts, the marginal counts are respectively
$(1,2^i)$, $(1,k)$ and $(2,k)$, so the Cartesian product has the same exact
sum $2kL-1$.

The full heuristic ADD is the complete address tree, so $A=k-1$ and
$\width_\pi(h)=k$ at the first cut after all address bits.
The BDD for $S$ is the length-$L$ conjunction chain, so $b=L$.
Its cofactor counts are one at the $r+1$ cuts through the complete address
prefix and two at each of the remaining $L-1$ cuts, giving
$\cofcount(\chi_S)=r+2L-1$.
Substitution yields the six primitive certificate relaxations
\[
\begin{array}{@{}rcl@{\qquad}rcl@{}}
kD&=&k(kL+k-1),
&mQ&=&k(kL+k+L-2),\\
mJ&=&k(2kL-1),
&C&=&k(2kL-1),\\
W&=&k^2(r+2L-1),
&A_{\mathrm{Apply}}&=&k(2kL+k-1).
\end{array}
\]
The layerwise meet is $B_\wedge=kD$ in this one-layer construction.
Since $L\geq r\geq1$, all seven certificate baselines are $\Theta(k^2L)$ and
$E=I=k(r+L)=\Theta(kL)$.
\end{proof}

\subsection{Terminal Relabeling and Exact-Effort Counterexample}

\begin{proposition}[contraction under terminal maps]
\label{prop:supp-incidence-contraction}
Let $\mathcal Y$ contain the terminal labels of $h$, let $\mathcal Z$ be any
output-label set and let $\phi\colon\mathcal Y\to\mathcal Z$.
Extend $\phi$ to a fresh bottom terminal
$\bot\notin\mathcal Y\cup\mathcal Z$ by $\phi(\bot)=\bot$.
For fixed $S$, replacing $h$ by $h'=\phi\circ h$ cannot increase
\begin{enumerate}
\item the active-terminal count;
\item masked ADD nodes, masked cofactor count or terminal incidence;
\item the co-occurring profile, Cartesian profile or cofactor width; or
\item the full heuristic ADD size.
\end{enumerate}
Every certificate on the right-hand sides of
Equations~\ref{eq:supp-cofactor-chain} and~\ref{eq:supp-add-branch} therefore
contracts.
Exact partition effort need not contract.
\end{proposition}

\begin{proof}
The active values of $h'$ on $S$ are the image of those of $h$, so their
number cannot increase.
Also
$\maskfun{S}{h'}=\phi\circ\maskfun{S}{h}$ when $\phi(\bot)=\bot$.
Relabeling terminals and reducing an ADD can only delete or merge decision
nodes and residual functions.
This proves contraction of masked nodes and masked cofactor count.

For incidence, map every old masked ADD node through terminal relabeling and
reduction.
For each inner node $u'$ that survives in the new ADD, choose one old node
$u$ whose relabeled residual reduces to $u'$.
The preimage classes of distinct $u'$ are disjoint, so the representatives
are distinct.
Moreover, the active terminals reachable from $u'$ are exactly a subset of
the images of active terminals reachable from $u$.
Thus $|T_{M'}(u')|\leq|T_M(u)|$.
Summing over the injectively chosen representatives proves
$\incidence{S}{h'}\leq\incidence{S}{h}$.

At every cut, $h'|_\rho=\phi\circ(h|_\rho)$.
The terminal map therefore maps old heuristic residuals onto new ones and
maps old co-occurring pairs onto new pairs.
Heuristic cut counts, width and the joint profile cannot increase.
Multiplication by the fixed state-set cut count proves contraction of the
Cartesian profile.
The same relabel-and-reduce argument proves contraction of the full heuristic
ADD.
All factors in the two branch bounds are nonnegative and individually
nonincreasing, while $S$ remains fixed, so every stated certificate contracts.

The following example proves the final claim.
Use order $x_1,x_2,x_3,x_4$ and let
\[
 F=\neg x_1\wedge\neg x_3\wedge\neg x_4,
 \qquad
 G=\neg x_2\wedge\neg x_3\wedge x_4.
\]
The sets are disjoint because they require opposite values of $x_4$.
Their BDDs are three-node chains on $(x_1,x_3,x_4)$ and
$(x_2,x_3,x_4)$, respectively.
Let $S=F\cup G$, assign heuristic value one on $F$, value two on $G$ and
zero outside $S$.
Then $\partcost{S}{h}=3+3=6$.

To count the BDD for the union, branch first on $x_1$.
The zero branch contains an $x_2$ node whose two residuals are
$\neg x_3$ and $\neg x_3\wedge\neg x_4$.
The one branch contains a different $x_2$ node whose two residuals are
$\neg x_3\wedge x_4$ and zero.
These branches require three distinct $x_3$ nodes.
The residuals $x_4$ and $\neg x_4$ share one regular $x_4$ node through
complemented edges.
Together with the root, the union BDD therefore has
$1+2+3+1=7$ regular inner nodes.
The uniform cap $\kappa=1$ merges the two heuristic terminals, produces the
single bucket $S$ and increases exact partition effort from six to seven.
This total $h$ has an admissible-consistent planning embedding: take the
assignment $1111\notin S$ as the sole goal and give every other assignment
one cost-three operator, with a complete-state precondition, that reaches the
goal.  Every non-goal state then has optimal cost three, so
$h\leq h^*$ and every transition satisfies consistency.
\end{proof}

Uniform caps are a special case of Proposition
\ref{prop:supp-incidence-contraction}.
The safety conditions for admissibility and consistency are proved later in
Proposition~\ref{prop-transform}.
That result maps finite values by
$a\mapsto\min(\max(0,a),\kappa)$ and preserves infinity.
The fixed-frontier contraction above is stronger than the older cofactor-only
statement, but the counterexample prevents a monotonicity claim for exact
partition effort.

\subsection{Incomparability of the Masked-Cofactor and Apply Certificates}

\begin{proposition}[certificate incomparability]
\label{prop:supp-branch-incomparability}
Neither $k\cofcount(\maskfun{S}{h})$ nor
$k(2(A+1)\bddsize{S}+A)$ is bounded by a constant multiple of the other over
all fixed frontiers and heuristics.
\end{proposition}

\begin{proof}
For the first direction, let $h$ be Hamming-weight parity and let $S$ contain
the assignments whose Hamming weight is zero modulo three.
For $n\geq3$, both parity values occur on $S$, so $k=2$.
The masked function returns terminal zero on weights congruent to zero modulo
six, terminal one on weights congruent to three modulo six and $\bot$
otherwise.
At every cut, its residual is determined by the prefix weight modulo six.
Hence it has at most six residuals per cut and
$k\cofcount(\maskfun{S}{h})=O(n)$.
It also depends on all $n$ variables, so the masked cofactor certificate is
$\Theta(n)$.
The ADD for parity and the BDD for weight modulo three each have
$\Theta(n)$ inner nodes under the natural order.
Therefore the ADD branch
$k(2(A+1)\bddsize{S}+A)$ is $\Theta(n^2)$.

For the opposite direction, take $h=x_1$ and $S=\{x_1=1\}$ with $x_1$
first in the order.
There is one active terminal.
The masked function has one residual at cut zero and its active and bottom
constants at every later cut, so
$k\cofcount(\maskfun{S}{h})=2n-1$.
The full heuristic ADD and the state-set BDD each have one inner node.
The ADD branch is therefore
$1\cdot(2(1+1)\cdot1+1)=5$.
The ratio between the two bounds grows with $n$, completing both
separations.
\end{proof}

The examples compare valid upper bounds, not the exact target.
They justify retaining the ADD certificate baseline alongside the cofactor
branch in the
confirmatory analysis.

The completed source census and its failed feasibility gate remain in the
artifact.

 c_P(a,b)=

\section{Search Setup and Bucket Identity}

Let \task\ be a finite deterministic planning task with positive integer
operator costs, initial state \sinit, and optimal solution cost
$0<\copt<\infty$.
For a state \(s\), let \(\gstar(s)\) be its cheapest-path cost from
\sinit, let \(L_g=\{s\mid\gstar(s)=g\}\), and let
\(\level{h}{v}=\{s\mid h(s)=v\}\).  The heuristic
\(h\colon\mathcal{S}\to\mathbb{Z}_{\geq0}\cup\{\infty\}\) is consistent if
\(h(s)\leq\cost(o)+h(s[o])\) for every applicable operator \(o\), and
\(h=0\) on goal states.  In \bddastar, states with infinite heuristic
value are discarded; the remaining generated states are grouped by keys
\((g,v)\), selected by increasing \(f=g+v\) and then increasing \(g\).
Each bucket is a set union that remains resident until its exact key is
selected. Immediately before expansion, its resident set is intersected with
the complement of states already closed at their best known $g$; ``bucket''
below means this residual set. Selection closes the entire residual bucket
before its successors are generated, and no state is reopened at an equal or
higher $g$. Search
terminates when a selected bucket contains a goal. This is the setting of the
following restatement.

\begin{lemma}[bucket identity]
\label{lem-identity}
Let $h$ be consistent. \bddastar\ on \task\ with $h$ selects every
bucket key $(g,v)$ with $g + v \leq \copt$ and $g < \copt$ and
$L_g \cap \level{h}{v} \neq \emptyset$ exactly once before terminating,
and the BDD expanded with key $(g,v)$ represents exactly
$L_g \cap \level{h}{v}$. No other bucket is expanded before
termination.
\end{lemma}

\begin{proof}
Throughout, the \emph{key} of a generated state $s$ is the pair
$(c, h(s))$, where $c$ is the cost of the generating path, and the
$f$-value of a key $(g,v)$ is $g + v$. We prove five claims.

\emph{Claim 1 (monotone selection): if a key $(g_1,v_1)$ is selected at
step $t_1$ and a key $(g_2,v_2)$ at step $t_2 > t_1$, then
$g_1 + v_1 \leq g_2 + v_2$, and if $g_1 + v_1 = g_2 + v_2$ then
$g_1 \leq g_2$.}
For the $f$-part, every state inserted into the open list during the
expansion of a bucket with key $(g,v)$ is a successor $s[o]$ of a state
$s$ with $h(s) = v$ and has key $(g + \cost(o),\, h(s[o]))$, whose
$f$-value satisfies
$g + \cost(o) + h(s[o]) \geq g + h(s) = g + v$ by consistency. Hence
expanding a minimum-$f$ key only inserts keys of at least that
$f$-value, the minimum $f$-value of the open list never decreases, and
selected $f$-values are non-decreasing over time. For the $g$-part,
suppose for contradiction that there are selections at steps
$t_1 < t_2$ of keys with equal $f$-value $F$ and $g_2 < g_1$, and among
all such violations choose one minimizing $t_2$. The bucket of
$(g_2,v_2)$ must be empty at step $t_1$: otherwise the tie-breaking
rule would select it instead of $(g_1,v_1)$. Its content is also not
inserted at step $t_1$ itself, since states inserted by the expansion
of $(g_1,v_1)$ have $g$-component $g_1 + \cost(o) > g_1 > g_2$. So
every state of the bucket is inserted at some step $t'$ with
$t_1 < t' < t_2$ by expanding a key $(g',v')$ with
$g' = g_2 - \cost(o) < g_2$ for some operator $o$. Consistency gives
$g' + v' \leq g_2 + v_2 = F$ as above, and the $f$-part applied to
$t_1 < t'$ gives $g' + v' \geq F$, so $g' + v' = F$ and $g' < g_1$:
the pair $(t_1, t')$ is a violation with $t' < t_2$, contradicting
minimality.

\emph{Claim 2 (no re-population): after a key $(g,v)$ is selected at
step $t$, no state with key $(g,v)$ is inserted into the open list;
consequently every key is selected at most once, and at its selection
its bucket contains every state that was ever generated with this key
and not expanded before.}
Suppose a state with key $(g,v)$ is inserted at a step $t' > t$ by
expanding a key $(g',v')$. Then $g' + v' \leq g + v$ by consistency as
in Claim~1, and $g' + v' \geq g + v$ by the $f$-part of Claim~1, so the
$f$-values are equal; but $g' = g - \cost(o) < g$ contradicts the
$g$-part. A second selection of the same key would require an
insertion after step $t$, which is excluded. Finally, a state generated
with key $(g,v)$ before step $t$ enters the bucket unless it is removed
by the closed-list test, which removes only previously expanded states,
and states are removed from the open list only when their bucket is
selected.

\emph{Claim 3 (optimal $g$-values): every state $s$ in a selected
bucket with key $(g,v)$ satisfies $\gstar(s) = g$ and $h(s) = v$.}
We use induction on the selection step; Claims~1 and~2 hold
unconditionally and may be used freely. That $h(s) = v$ holds by
construction of the level-set partition, and $\gstar(s) \leq g$ because
$s$ is reached by a path of cost $g$. Suppose $\gstar(s) < g$ for some
$s$ in the bucket selected at the current step, and fix a cheapest path
$p_0 = \sinit, \dots, p_k = s$, all of whose prefixes are cheapest
paths to their end states. Let $j$ be the smallest index such that
$p_j$ has not been expanded before the current step; $j$ exists because
$s$ qualifies, and $j \geq 1$ because \bddastar\ selects the initial
bucket $\{\sinit\}$ first. By the induction hypothesis, every earlier
expansion of $p_{j-1}$ has key $(\gstar(p_{j-1}), h(p_{j-1}))$, so
$p_j$ was generated with key $(\gstar(p_j), h(p_j))$ before the current
step. This key has not been selected yet: a selection after the
generation of $p_j$ would have expanded $p_j$ (Claim~2), contradicting
the choice of $j$, and a selection before the generation would
contradict Claim~2 directly. Hence the open list currently contains the
key $(\gstar(p_j), h(p_j))$, and consistency along the path segment
from $p_j$ to $s$ yields
$\gstar(p_j) + h(p_j) \leq \gstar(s) + h(s) < g + v$, using
$\gstar(s) < g$ and $h(s) = v$. This contradicts minimum-$f$ selection.

\emph{Claim 4 (completeness): every state $s$ with
$\gstar(s) = g < \copt$ and $g + h(s) \leq \copt$ is generated with key
$(g, h(s))$, and this key is selected before the search terminates.}
By strong induction on $g$. \emph{Generation:} for $g = 0$, $s = \sinit$
initializes the open list with key $(0, h(\sinit))$. For $g > 0$, let
$p$ be the predecessor of $s$ on a cheapest path, with
$\gstar(p) = g - \cost(o) < g$ and, by consistency,
$\gstar(p) + h(p) \leq \gstar(s) + h(s) \leq \copt$. By the induction
hypothesis, $p$ is generated with key $(\gstar(p), h(p))$ and this key
is selected before termination; by Claim~2 the bucket then contains
$p$, because any earlier expansion of $p$ would, by Claim~3, have
occurred with the same key, which is selected only once. Expanding the
bucket generates $s$ at cost $\gstar(p) + \cost(o) = g$ with key
$(g, h(s))$. \emph{Selection:} let $K = (g, h(s))$, with
$f(K) \leq \copt$ and $g < \copt$. From the step at which $K$ first
becomes nonempty, $K$ remains in the open list until it is selected
(Claim~2). The search terminates only when a selected bucket contains a
goal state, and by Claim~3 a goal state in a selected bucket has key
$(\gstar(s_G), 0)$ with $\gstar(s_G) \geq \copt$, since consistent
heuristics assign $0$ to goal states and \copt\ is the cheapest goal
cost. While $K$ is open, no such key is selected: its $f$-value is at
least $\copt \geq f(K)$, and in case of equality its $g$-component
$\gstar(s_G) \geq \copt > g$ loses the tie-break against $K$ or another
open key with smaller $g$-component. Hence the search does not
terminate while $K$ is open. Moreover, while $K$ is open every
selection picks a key with $f$-value at most $f(K) \leq \copt$; there
are at most $(\copt + 1)(\copt + 2)/2$ keys $(g', v')$ of nonnegative
integers with $g' + v' \leq \copt$, each selected at most once
(Claim~2), and the open list is nonempty while $K$ is open. Hence after
finitely many steps $K$ itself is selected, before termination.

\emph{Claim 5 (no other expansions): every bucket selected before the
terminating selection has a key $(g,v)$ with $g + v \leq \copt$ and
$g < \copt$.}
Fix a cheapest plan $q_0 = \sinit, \dots, q_r$ with $q_r$ a goal state
and all prefixes cheapest, so that consistency yields
$\gstar(q_l) + h(q_l) \leq \copt$ for every $l$. First we exhibit a
witness key: at every step at which the search has not yet terminated,
let $l$ be the smallest index such that $q_l$ is unexpanded, which
exists because $q_r$ is unexpanded before termination. If $l = 0$, the
initial key $(0, h(\sinit))$ has not been selected, since its bucket
contains $\sinit$, and is therefore open. If $l \geq 1$, then $q_{l-1}$
was expanded, by Claim~3 with key $(\gstar(q_{l-1}), h(q_{l-1}))$, so
$q_l$ was generated with key $K_l = (\gstar(q_l), h(q_l))$; exactly as
in the proof of Claim~3, $K_l$ has not been selected and is therefore
open. In all cases the open list contains a key with $f$-value at most
\copt, namely $(0, h(\sinit))$ or $K_l$; call it the witness. Second,
minimum-$f$ selection against the witness implies that every selected
key satisfies $g + v \leq \copt$. Third, a selected key with
$g + v \leq \copt$ and $g \geq \copt$ must equal $(\copt, 0)$, and we
show that its selection is the terminating one. Consider the step at
which $(\copt, 0)$ is selected and let $l$ be as above. If $l < r$,
the witness $K_l$ is open with $f$-value at most \copt\ and
$g$-component $\gstar(q_l) < \copt$; then either its $f$-value is
smaller than \copt, contradicting minimum-$f$ selection of
$(\copt, 0)$, or it equals \copt\ and the tie-breaking rule prefers
$K_l$ or another open key of smaller $g$-component over $(\copt, 0)$,
again a contradiction. Hence $l = r$, so $q_r$ was generated with key
$(\copt, 0)$ and, being unexpanded, lies in its bucket at selection
time by Claim~2. The selected bucket thus contains the goal state
$q_r$ and the search terminates. Consequently, every selection before
the terminating one has $g + v \leq \copt$ and $g < \copt$.

\emph{Assembly.} Let $(g,v)$ with $g + v \leq \copt$ and $g < \copt$
and $L_g \cap \level{h}{v} \neq \emptyset$. Every
$s \in L_g \cap \level{h}{v}$ satisfies the premise of Claim~4, so its
key $(g,v)$ is selected exactly once before termination (Claims~2
and~4), and at this selection the bucket contains $s$ (Claim~2, with
prior expansion of $s$ excluded because, by Claim~3, it would have
occurred at the same, uniquely selected key). Conversely, by Claim~3
the selected bucket contains only states with $\gstar = g$ and
$h$-value $v$. Hence the expanded BDD represents exactly
$L_g \cap \level{h}{v}$. Keys whose intersection is empty are never
selected, since buckets enter the open list only when populated, and by
Claim~5 no key outside the stated range is expanded before the search
stops.
\end{proof}

\section{Fixed-Order Residual-Width Notation and Auxiliary Results}

The maximum number of distinct residual functions at a fixed-order cut is the
standard width measure for ordered branching programs and MTBDDs
\citep[Thm.~3.2.2; Sec.~9.2]{wegener-2000}. We use
\emph{cofactor width} as a planning-facing name for this existing measure.
This archived section studies its application to heuristic fragmentation and
forward product-at-evaluation search, its separation constructions and the
planning-heuristic family bounds; the width definition itself is standard.

Fix Boolean variables $x_1,\dots,x_n$ in an order $\pi$.  For a Boolean
or integer-valued function $f$ and a prefix assignment
$\rho\in\{0,1\}^i$, write $f|_\rho$ for the residual function after the
prefix and
$\sub{i}{f}=\{f|_\rho\mid\rho\in\{0,1\}^i\}$.  The cofactor count and
cofactor width are
\[
  \cofcount(f)=\sum_{i=0}^{n-1}|\sub{i}{f}|,
  \qquad
  \width_\pi(f)=\max_{0\leq i\leq n}|\sub{i}{f}|.
\]
Write $\cutcount{i}{f}=|\sub{i}{f}|$. For a state set $S$ and heuristic
$h$, define the co-occurring residual-pair count and its cumulative profile by
\[
 \jointcount{i}{S}{h}=
 \left|\left\{(\chi_S|_\rho,h|_\rho)
       \mid\rho\in\{0,1\}^i\right\}\right|,
 \qquad
 \jointprofile{S}{h}=\sum_{i=0}^{n-1}\jointcount{i}{S}{h}.
\]
Their cut-aligned Cartesian profile product is
\[
  \cutprod{S}{h}=\sum_{i=0}^{n-1}
  \cutcount{i}{\chi_S}\cutcount{i}{h}.
\]
Projection onto either component and inclusion in the Cartesian product give
\[
 \max\{\cutcount{i}{\chi_S},\cutcount{i}{h}\}
 \leq\jointcount{i}{S}{h}
 \leq\cutcount{i}{\chi_S}\cutcount{i}{h}
\]
at every cut. Thus $\jointprofile{S}{h}\leq\cutprod{S}{h}$, with equality
only when every cross-pair is realized at every cut.
For a Boolean function $f$, $\bdd{f}$ is its reduced ordered BDD with
complemented edges under $\pi$, and $\bddsize{f}$ counts regular inner
nodes, as in CUDD. A residual is represented by a signed pointer: its regular
node together with its polarity. Thus $f$ and $\neg f$ may share all regular
nodes but remain distinct residual functions. For a heuristic $h$,
$\hrange(h)$ is its attained value set.  The blind heuristic $\hblind$ is
identically zero, and $\effort(\task,h)$ is the cumulative number of inner
nodes in the BDDs expanded by product-at-evaluation forward \bddastar\ before
optimal termination.
Each SAS$^+$ variable $v$ is encoded using
$\lceil\log_2|D_v|\rceil$ Boolean bits; the order $\pi$ is
variable-contiguous when all bits of each variable are consecutive. This
encoding may leave invalid Boolean assignments. A heuristic on states is
equipped with a fixed total extension to the full Boolean cube; where
relevant below, the statements specify that extension.

\begin{proposition}[value range]
\label{prop-range}
If $\width_\pi(h) \leq W$, then $|\hrange(h)| \leq W$.
\end{proposition}

\begin{proof}
The elements of $\sub{n}{h}$ are constant functions, one for each attained
value. Hence $|\hrange(h)|=|\sub{n}{h}|\leq\width_\pi(h)$.
\end{proof}

\begin{proposition}[closure]
\label{prop-closure}
Let $h_1,h_2$ have widths $W_1,W_2$ under $\pi$ and let
$\oplus\in\{+,\max,\min\}$. Then
$\width_\pi(h_1\oplus h_2)\leq W_1W_2$.
\end{proposition}

\begin{proof}
At cut $i$, each cofactor of $h_1\oplus h_2$ is the pointwise combination
of a realized pair $(h_1|_\rho,h_2|_\rho)$. There are at most
$|\sub{i}{h_1}|\,|\sub{i}{h_2}|\leq W_1W_2$ such pairs. Maximizing over
$i$ proves the claim.
\end{proof}

Call $q\colon\states\to\mathbb Z\cup\{\infty\}$ a \emph{raw admissible
and consistent estimate} if $q\leq\hstar$, if
$q(s)\leq c+q(s')$ for every transition $s\xrightarrow{c}s'$, and if
$q\leq0$ on goals.

\begin{proposition}[safe terminal transforms]
\label{prop-transform}
Let $q$ be a raw admissible and consistent estimate, equipped with a total
extension $q\colon\{0,1\}^n\to\mathbb Z\cup\{\infty\}$. Let
$\phi\colon\mathbb Z\cup\{\infty\}\to
\mathbb Z_{\geq0}\cup\{\infty\}$ be nondecreasing, satisfy
$\phi(0)=0$, $\phi(\infty)=\infty$, and
\[
  \phi(a+c)\leq\phi(a)+c
  \quad\text{for every $a\in\mathbb Z$ and integer $c\geq0$.}
\]
Then $h=\phi\circ q$ is admissible and consistent and
$\cutcount{i}{h}\leq\cutcount{i}{q}$ for every cut $i$. Consequently,
$\width_\pi(h)\leq\width_\pi(q)$ and
$\jointprofile{S}{h}\leq\jointprofile{S}{q}$ and
$\cutprod{S}{h}\leq\cutprod{S}{q}$ for every fixed state set $S$.
\end{proposition}

\begin{proof}
For a transition $s\xrightarrow{c}s'$ with finite $q(s')$,
\[
  \phi(q(s))\leq\phi(c+q(s'))\leq c+\phi(q(s'));
\]
if $q(s')=\infty$, consistency is immediate. Monotonicity,
nonnegativity, and $\phi(0)=0$ give $\phi(a)=0$ for $a\leq0$, while the
cost condition with $a=0$ gives $\phi(a)\leq a$ for $a\geq0$. Thus, for
finite $q(s)$,
$\phi(q(s))\leq\max(0,q(s))\leq\hstar(s)$. If $q(s)=\infty$, raw
admissibility implies $\hstar(s)=\infty$. The transformed heuristic is
therefore admissible, consistent, and zero on goals. Finally,
$(\phi\circ q)|_\rho=\phi\circ(q|_\rho)$, so the terminal map may merge
cofactors but cannot create any. Moreover,
$(\chi_S|_\rho,q|_\rho)\mapsto
(\chi_S|_\rho,\phi\circ(q|_\rho))$ maps the old co-occurring pairs onto the
new ones, so their number cannot increase. This proves the joint-profile
inequality. Taking a maximum proves the width inequality, and multiplying by
the nonnegative state-set cut counts and summing proves the Cartesian-profile
inequality.
\end{proof}

Rectification $\phi_+(a)=\max(0,a)$ is one instance. For
$\kappa\in\mathbb Z_{\geq0}$, define
\[
\phi_\kappa(a)=
\begin{cases}
\min(\max(0,a),\kappa),&a<\infty,\\
\infty,&a=\infty.
\end{cases}
\]
It satisfies the proposition and has at most $\kappa+1$ finite values.
Moreover, it is pointwise strongest among transforms satisfying the
proposition whose finite outputs lie in $\{0,\ldots,\kappa\}$: the proof
above and the output ceiling give
$\phi(a)\leq\min(\max(0,a),\kappa)=\phi_\kappa(a)$.
For $\kappa_1\leq\kappa_2$,
$\phi_{\kappa_1}=\phi_{\kappa_1}\circ\phi_{\kappa_2}$ on the attained
terminals. Hence $\phi_{\kappa_1}\circ q$ is a terminal relabeling of
$\phi_{\kappa_2}\circ q$ and
$\width_\pi(\phi_{\kappa_1}\circ q)\leq
\width_\pi(\phi_{\kappa_2}\circ q)$. Thus increasing $\kappa$ weakly
strengthens the heuristic, whereas decreasing it weakly contracts every cut
count, both profiles with any fixed set, and the coarse $2\values Wn$
certificate. This does not assert monotonicity of run-level profiles: changing
the heuristic may change the expanded sets to which they are applied.

Let $\mathrm{ADD}_\pi(h)$ be the reduced ordered ADD of $h$ under $\pi$
\citep{bahar-et-al-iccad1993}, and let $|\mathrm{ADD}_\pi(h)|$ count
inner nodes.

\begin{proposition}[ADD characterization]
\label{prop-add}
$\width_\pi(h)\leq|\mathrm{ADD}_\pi(h)|+|\hrange(h)|$ and
$|\mathrm{ADD}_\pi(h)|\leq n\width_\pi(h)$.
\end{proposition}

\begin{proof}
Every cofactor at a cut is either a constant or the function computed by a
unique inner ADD node below the cut, giving the first inequality. Every
inner node labeled $x_{i+1}$ computes a distinct element of
$\sub{i}{h}$, so there are at most $\width_\pi(h)$ nodes at each of the
$n$ levels, giving the second.
\end{proof}

\begin{remark}[total extensions]
\label{rem-encoding}
Cofactor width is measured on the chosen total extension, while a lower
bound witnessed entirely by genuine states applies to every such extension.
\end{remark}

\section{Reduced and Quasi-Reduced OBDD Size}

\begin{lemma}
\label{lem-qsize}
For every Boolean $f$ over $x_1, \dots, x_n$,
$\bddsize{f} \leq \cofcount(f) \leq n \cdot (\bddsize{f} + 2)$.
If $f$ is nonconstant, then also
$\cofcount(f)\leq2n\bddsize{f}$.
\end{lemma}

\begin{proof}
For the first inequality, consider a regular node $N$ of $\bdd{f}$ labeled
$x_{i+1}$. Since every node of a reduced OBDD is reachable from the root,
there is a path from the root to $N$; fixing the variables tested along
this path to the corresponding edge values and all remaining variables
among $x_1, \dots, x_i$ arbitrarily yields a prefix $\rho \in \{0,1\}^i$
whose signed residual pointer has regular node $N$, because variables skipped
by long edges do not influence the traversal. Distinct regular nodes give
distinct signed pointers, so the map is injective.
Summing over $i$ gives
$\bddsize{f} \leq \sum_{i=0}^{n-1} |\sub{i}{f}| = \cofcount(f)$. For the
second inequality, fix $i$. Let $U$ be the number of regular inner nodes
above the cut and $D$ the number of distinct regular nonterminal nodes on
the projected frontier. Let $\delta$ indicate whether the regular terminal
is reached, let $r\leq D$ count frontier nodes reached in both polarities,
and let $t\leq2$ count the signed constant residuals. The projected regular
truncated DAG is binary, so $D+\delta\leq U+1$. The polarity-sensitive
residual count is
\[
 |\sub{i}{f}|=D+r+t.
\]
If $t=0$, this is at most $D+U+1$; if $t>0$, then $\delta=1$, hence
$D\leq U$, and the count is at most $D+U+2$. In both cases it is at most
$\bddsize{f}+2$, because the complete diagram contains at least the $U+D$
regular inner nodes. Summing proves the second claim. For the final
inequality, write $b=\bddsize{f}\geq1$. If $b\geq2$, then
$n(b+2)\leq2nb$. If $b=1$, the unique inner node tests some $x_j$, so $f$
is $x_j$ or $\neg x_j$. The cuts before $x_j$ have one residual and the
remaining cuts have two constants. Thus
$\cofcount(f)=j+2(n-j)=2n-j\leq2n=2nb$.
\end{proof}

\section{Fragmentation Bounds}

Fix a heuristic $h$ of width $W$ under $\pi$ and let
$T=|\hrange(h)|$.

\begin{lemma}[pair identity]
\label{lem-pair}
Let $S\subseteq\{0,1\}^n$, let $U\subseteq\hrange(h)$, and let
$\rho,\rho'\in\{0,1\}^i$ satisfy
$\chi_S|_\rho=\chi_S|_{\rho'}$ and $h|_\rho=h|_{\rho'}$. Then
$\chi_{S\cap h^{-1}(U)}|_\rho=
\chi_{S\cap h^{-1}(U)}|_{\rho'}$.
\end{lemma}

\begin{proof}
For every suffix $\sigma\in\{0,1\}^{n-i}$,
\[
 \chi_{S\cap h^{-1}(U)}|_\rho(\sigma)
 =\chi_S|_\rho(\sigma)[h|_\rho(\sigma)\in U].
\]
Both factors are unchanged when $\rho$ is replaced by $\rho'$, proving
equality of the residual functions.
\end{proof}

\begin{theorem}[bucket bound]
\label{thm-bucket}
Let $S\subseteq\{0,1\}^n$ and $U\subseteq\hrange(h)$. Then
\[
\bddsize{S\cap h^{-1}(U)}
\leq\cofcount(\chi_{S\cap h^{-1}(U)})
\leq\jointprofile{S}{h}
\leq\cutprod{S}{h}
\leq W\cofcount(\chi_S)
\leq Wn(\bddsize{S}+2).
\]
\end{theorem}

\begin{proof}
The first and last inequalities follow from Lemma~\ref{lem-qsize}. Fix a
cut $i$ and let
\[
 R_i=\{(\chi_S|_\rho,h|_\rho)\mid\rho\in\{0,1\}^i\}.
\]
For each $u\in\sub{i}{\chi_{S\cap h^{-1}(U)}}$, choose a witnessing
prefix $\rho_u$ and map $u$ to
$(\chi_S|_{\rho_u},h|_{\rho_u})\in R_i$. This map is injective by
Lemma~\ref{lem-pair}. Consequently,
\[
 |\sub{i}{\chi_{S\cap h^{-1}(U)}}|
 \leq|R_i|=\jointcount{i}{S}{h}
 \leq\cutcount{i}{\chi_S}\cutcount{i}{h}
 \leq W|\sub{i}{\chi_S}|.
\]
Summing before and after the relaxation to $W$ proves the two middle
inequalities.
\end{proof}

\begin{theorem}[partition bound]
\label{thm-partition}
Let $S\subseteq\{0,1\}^n$. Then
\[
 \sum_{v\in\hrange(h)}\bddsize{S\cap\level{h}{v}}
 \leq T\jointprofile{S}{h}
 \leq T\cutprod{S}{h}
 \leq TW\cofcount(\chi_S)
 \leq TWn(\bddsize{S}+2)
 \leq W^2n(\bddsize{S}+2).
\]
If $S\subseteq\states$ and the sum ranges only over finite values attained
on planning states, every $T$-dependent bound holds with $T$ replaced by
$\values=|h(\states)\setminus\{\infty\}|$.
\end{theorem}

\begin{proof}
Theorem~\ref{thm-bucket} with $U=\{v\}$ bounds every bucket by
$\jointprofile{S}{h}$. Sum over the $T$ terminals, relax first to the
Cartesian profile and then to width, and use
$T\leq W$ from Proposition~\ref{prop-range}; Lemma~\ref{lem-qsize}
converts cofactor count to reduced size. If only finite values attained on
planning states are included, there are at most $\values$ nonempty
buckets.
\end{proof}

\begin{example}[the factor $n$ is necessary]
\label{ex-parity}
For $n\geq2$, let $S=\{s\mid s(x_1)=1\}$ and
$h(s)=(\sum_{i=1}^ns(x_i))\bmod2$. Then $\bddsize{S}=1$ and $h$ has
width two under any order. The bucket $S\cap\level{h}{0}$ fixes
$x_1=1$ and requires odd parity on $x_2,\ldots,x_n$. Its reduced BDD has
one node for $x_1$ and one parity node for each of
$x_2,\ldots,x_n$, hence $n$ regular inner nodes; complemented edges share
the opposite-parity residuals. Thus a width-two slice can be
$\Theta(n)$ times larger than its source set. In cofactor count,
$\cofcount(\chi_S)=2n-1$, so Theorem~\ref{thm-bucket} is within a
constant factor.
\end{example}

\begin{remark}[comparison with a total-ADD-size certificate]
Let $A$ be the number of inner nodes in the reduced total ADD for $h$, and
write $b=\bddsize{S}$. For any terminal set $U$, relabeling terminals by
membership in $U$ and reducing produces an ordinary Boolean OBDD for
$h^{-1}(U)$ with at most $A$ inner nodes
\citep[Sec.~9.2]{wegener-2000}. Materializing both
polarities of $S$ gives an ordinary OBDD with at most $2b$ inner nodes.
Standard synchronous Boolean Apply for conjunction
\citep[Sec.~4.3]{bryant-ieeecomp1986} creates at most one output node for
each pair of internal operand nodes and for each pair in which one operand is
internal and the other is the 1-terminal.
Hence
\[
 \bddsize{S\cap h^{-1}(U)}
 \leq\min\{\jointprofile{S}{h},\,2(A+1)b+A\},
\]
where the first certificate is Theorem~\ref{thm-bucket}.  More precisely, if
$b_g=\bddsize{L_g}$ and $\values_g$ is the number of nonempty selected
buckets on layer $g$, the standing bucket-identity assumptions give the
combined search-level certificate
\[
 \effort(\task,h)
 \leq\sum_{\substack{g<\copt\\L_g\ne\emptyset}}
 \values_g\min\{\jointprofile{L_g}{h},\,2(A+1)b_g+A\}.
\]
Relaxing this to the Apply term and using at most $\values$ buckets on each
of the $N$ nonempty layers below $\copt$ gives
\[
 \effort(\task,h)
 \leq\values\bigl(2(A+1)\effort(\task,\hblind)+AN\bigr)
 \leq\values(3A+2)\effort(\task,\hblind),
\]
because $N\leq\effort(\task,\hblind)$. A nonconstant ADD has one root and at
most $W$ nodes at each of the other $n-1$ levels, so
$A\leq1+(n-1)W$. Since a nonconstant function has $W\geq2$, this implies
$3A+2\leq3nW$; for a constant function, $A=0$. The reduced-size baseline is
therefore at most $3\values Wn$. A rooted binary ADD
with $A$ inner nodes reaches at most
$A+1$ terminals, so $\values\leq A+1$ also gives the ADD-only ratio
$(A+1)(3A+2)$.

The two bounds are nevertheless incomparable before cofactor count is relaxed.
Let $h$ be Hamming-weight parity and let $S$ contain assignments whose Hamming
weight is $0$ modulo $3$. Under the natural order, $W=2$, while the reduced
ADD for $h$ and BDD for $S$ both have $\Theta(n)$ nodes. The slice
$S\cap h^{-1}(\{0\})$ is weight $0$ modulo $6$ and also has a constant-width,
$\Theta(n)$-node OBDD.
Thus $\cutprod{S}{h}=\Theta(n)$ while $2(A+1)b+A=\Theta(n^2)$. In the other
direction, take $h=x_1$ and $S=\{x_1=1\}$. Then $A=b=1$ but
$\cofcount(\chi_S)=2n-1$, so the CUDD-safe Apply certificate gives $5$ while
the cofactor bound is
$\cutprod{S}{h}=4n-3$. The profile certificate supplies cut-sensitive and
compositional structure; we do not claim it is a universally tighter
operational selector than total ADD size.
\end{remark}

\section{Search-Effort Bound}

By Lemma~\ref{lem-identity}, expansion size is exactly
\[
 \effort(\task,h)
 =\sum_{g<\copt}\ \sum_{\substack{v\in\hrange(h)\\g+v\leq\copt}}
   \bddsize{L_g\cap\level{h}{v}}.
\]

\begin{theorem}[effort bound]
\label{thm-effort}
Let $h$ be consistent with $\width_\pi(h)\leq W$, and let
$\values=|h(\states)\setminus\{\infty\}|$.  For each $g$, let
\[
 \values_g=
 |\{v\in h(\states)\setminus\{\infty\}\mid
 g+v\leq\copt,\ L_g\cap\level{h}{v}\ne\emptyset\}|.
\]
Then
\[
 \begin{aligned}
 \effort(\task,h)
 &\leq\sum_{\substack{g<\copt\\L_g\ne\emptyset}}
      \values_g\jointprofile{L_g}{h} \\
 &\leq\sum_{\substack{g<\copt\\L_g\ne\emptyset}}
      \values_g\cutprod{L_g}{h} \\
 &\leq\values
   \sum_{\substack{g<\copt\\L_g\ne\emptyset}}
     \cutprod{L_g}{h} \\
 &\leq\values W
   \sum_{\substack{g<\copt\\L_g\ne\emptyset}}
     \cofcount(\chi_{L_g}) \\
 &\leq\values Wn\bigl(\effort(\task,\hblind)+2\copt\bigr) \\
 &\leq W^2n\bigl(\effort(\task,\hblind)+2\copt\bigr).
 \end{aligned}
\]
\end{theorem}

\begin{proof}
Lemma~\ref{lem-identity} selects exactly these $\values_g$ buckets on layer
$g$, and Theorem~\ref{thm-bucket} bounds each bucket by
$\jointprofile{L_g}{h}$. This proves the first inequality. Relaxing to the
Cartesian profile proves the second. The next two follow from
$\values_g\leq\values$ and
$\cutprod{L_g}{h}\leq W\cofcount(\chi_{L_g})$.
Lemma~\ref{lem-qsize} then bounds each cofactor count by
$n(\bddsize{L_g}+2)$.
Let $N$ be the number of nonempty layers below $\copt$. Since blind
search expands each such layer once,
\begin{equation}
 \effort(\task,h)
 \leq\values Wn\bigl(\effort(\task,\hblind)+2N\bigr).
 \label{eq-effort-nonempty}
\end{equation}
Positive integer costs imply $N\leq\copt$: the possible layer indices are
$0,\ldots,\copt-1$. This proves the penultimate inequality, and
$\values\leq W$ proves the last.
\end{proof}

\begin{corollary}[search-effort ratio]
\label{cor-effort}
Under the assumptions of Theorem~\ref{thm-effort},
\begin{equation}
 \effort(\task,h)
 \leq2\values Wn\,\effort(\task,\hblind)
 \leq2W^2n\,\effort(\task,\hblind).
 \label{eq-supp-effort-ratio}
\end{equation}
\end{corollary}

\begin{proof}
Positive costs give $L_0=\{\sinit\}$. Because
$0<\copt<\infty$, this is a proper subset of the Boolean cube. Every
nonempty $L_g$ with $0<g<\copt$ is also proper because it omits
\sinit. Hence each $\chi_{L_g}$ is nonconstant, and
Lemma~\ref{lem-qsize} gives
$\cofcount(\chi_{L_g})\leq2n\bddsize{L_g}$. Substitution in the third
inequality of Theorem~\ref{thm-effort}, followed by summation over $g$,
proves both inequalities.
\end{proof}

This is a one-sided bound on expanded frontier representations in forward
product-at-evaluation \bddastar. It neither bounds the primitive relational
products of delta-partitioned methods nor gives a cumulative bidirectional
guarantee; it does allow unbounded savings through $f$-cutoff and dead-end
pruning.

\section{Image Calls and Pruning-Only Search}

\begin{definition}[image-aware effort]
For $\alpha\geq0$, the \emph{$\alpha$-effort} of a symbolic run is
\[
 \effort_\alpha=\sum_B(\alpha+|B|),
\]
where the sum ranges over idealized high-level cost-image invocations before
termination and $B$ is the argument of the invocation.
\end{definition}

For $\alpha=0$, this is the expansion-size measure only in the idealized case
where each expanded bucket is exactly the argument of one high-level
cost-image invocation.

\begin{proposition}[image-call counts]
\label{prop-calls}
Let $h$ be consistent with $\width_\pi(h)\leq W$, and let $N_\ell$ be
the number of nonempty semantic blind layers $L_g$ with $g<\copt$. An
idealized blind implementation storing each semantic $L_g$ in one BDD performs
$N_\ell$ counted high-level cost-image invocations, one per nonempty semantic
layer. An idealized product-at-evaluation
\bddastar\ performing one high-level cost-image invocation per expanded
nonempty $(g,v)$ bucket performs $\sum_g\values_g$ counted invocations, where
$\values_g$ is the number of nonempty expanded buckets in layer $g$ and
$\values_g\leq\values\leq W$; hence it performs at most
$\values N_\ell\leq WN_\ell$ counted invocations.
\end{proposition}

\begin{proof}
The idealized blind implementation invokes the high-level cost-image routine
once for each nonempty semantic layer.
Lemma~\ref{lem-identity} makes every active heuristic layer a blind layer
below $\copt$, and partitions it into exactly $\values_g$ nonempty
buckets. Proposition~\ref{prop-range} gives
$\values_g\leq\values\leq W$.
\end{proof}

Thus the invocation-overhead term is at most $\alpha WN_\ell$, but width does
not provide a width-independent one-call-per-layer guarantee. Here one
count means one idealized invocation of the high-level cost-image routine per
semantic layer or bucket, not every relational product it performs. In
particular, the proposition does not
apply verbatim to SetA$^*$ or cost-general \ghseta: operator-potential
implementations partition transition relations by operator-cost and
heuristic-delta pairs, so their relational-product count also depends on
those partitions. The exact finite value count $\values$ can therefore be
a much sharper operational parameter than an ADD-derived width bound, while
delta-integrated search requires a separate analysis
\citep{fiser-et-al-aij2024}. On the joint-tightness construction below, the
idealized model counts exactly $\values$ high-level cost-image invocations on
each of $B$ persistent semantic layers, so the value-count factor is
realizable independently of width.

\emph{Pruning-only search} instead maintains one BDD per uniform-cost
layer and an incumbent solution bound $c$ ($c=\infty$ initially). It
discards $h=\infty$ and states satisfying $g+h\geq c$, and reapplies the
current bound when a layer is expanded. It stops when the next layer cannot
improve the incumbent. Layers are selected in strictly increasing $g$ after
best-$g$ duplicate elimination; a selected layer is closed before its image is
generated. A goal in that generated successor set updates $c$ before the next
layer is imaged.

\begin{lemma}[slice identity]
\label{lem-slice}
Let $h$ be consistent, and let $c_g$ be the incumbent when pruning-only
search expands layer $g$. The expanded layer is exactly
\[
 L_g\cap h^{-1}(\{v\mid v<c_g-g\}).
\]
\end{lemma}

\begin{proof}
Applying $c_g$ at expansion gives containment in the displayed slice. For
the converse, let $s\in L_g$ satisfy $g+h(s)<c_g$, and take a cheapest
path $p_0=\sinit,\ldots,p_k=s$. Consistency gives
$\gstar(p_j)+h(p_j)\leq g+h(s)<c_g$ for every prefix state. Its layer was
expanded no later than $g$, when the nonincreasing incumbent was at least
$c_g$, so $p_j$ survived generation-time and expansion-time pruning.
Induction along the path shows that $s$ is generated at cost $g$ and
survives into the expanded layer.
\end{proof}

\begin{corollary}[pruning bound]
\label{cor-prune}
Let $h$ be admissible and consistent with $\width_\pi(h)\leq W$. The
cumulative size of the layers expanded by pruning-only search is at most
\[
 2Wn\,\effort(\task,\hblind),
\]
and it performs one idealized high-level cost-image invocation per expanded
semantic layer. With $c=\infty$
throughout and no recognized dead ends, its semantic layers and expansions
coincide with blind forward search, although heuristic construction and
evaluation can still consume time.
\end{corollary}

\begin{proof}
By Lemma~\ref{lem-slice}, every expanded BDD is a single threshold slice
of $L_g$. Theorem~\ref{thm-bucket} bounds it by
$W\cofcount(\chi_{L_g})\leq2Wn\bddsize{L_g}$, because every nonempty
pre-goal $L_g$ is proper and Lemma~\ref{lem-qsize} applies. While
$c>\copt$, admissibility preserves every prefix
of an optimal plan because $g+h\leq\copt<c$. Imaging its final pre-goal prefix
generates a goal of cost $\copt$ and updates $c$ before another layer is
imaged. The stopping rule therefore prevents an image at $g\geq\copt$.
Summing over the expanded layers below the optimal goal cost, and enlarging
to all blind pre-goal layers, proves the node bound. Because no layer is
partitioned, exactly one modeled high-level cost-image invocation is made for
each expanded semantic layer. If the incumbent stays infinite and no state
has $h=\infty$, the retained slice
is all of $L_g$, proving the final claim.
\end{proof}

For every $\alpha\geq0$, pruning-only $\alpha$-effort is therefore at
most
\[
 2Wn\,\effort(\task,\hblind)+\alpha N_\ell.
\]
The discard is also pointwise sound in bidirectional blind search if the
forward direction uses an admissible goal-distance estimate and the
backward direction an admissible distance-from-initial estimate. We do not
lift this pointwise fact to a cumulative bidirectional bound: pruning
changes both closed sets and their meeting points, which can alter solution
discovery, incumbent updates, and an adaptive direction schedule. Those
feedback effects prevent identification with fixed blind reference
frontiers. A single linear merge-and-shrink abstraction can supply both
goal-distance and distance-from-initial estimates from the same shrunk
transition system. Pointwise incumbent pruning itself uses only
admissibility and, unlike the cumulative layer argument above, does not
require positive operator costs.

\section{Joint Tightness of the Coarse Ratio}

\begin{theorem}[joint lower bound]
\label{thm-tight}
For every $2\leq\values\leq W$ and every power of two $B\geq4W$, there
is a polynomial-size task with $n=\Theta(B)$ Boolean state bits and a
consistent, admissible heuristic $h$ with exactly $\values$ finite values and
$\width_\pi(h)=W$ such that
\[
  \frac{\effort(\task,h)}{\effort(\task,\hblind)}
  \geq \frac{\values Wn}{120}.
\]
\end{theorem}

\begin{proof}
Write $B=2^m$, set $C=\values-1$, and let $N=2B+m$.  The task has an
$m$-bit address $a$, modular bits $y_1,\ldots,y_B$, data bits
$z_0,\ldots,z_{B-1}$, a goal bit $t$, and a control variable with generation
values $c_0,\ldots,c_N$ and persistent values $s_0,\ldots,s_{B-1}$.  Encode
the control variable with
\[
 q=\left\lceil\log_2(N+B+1)\right\rceil
\]
Boolean bits.  The order $\pi$ lists the control bits, the address bits, the
$y$-bits, the $z$-bits, and $t$, in that order.  Thus
\[
 n=q+m+2B+1=2B+O(\log B)=\Theta(B).
\]

Initially the control is $c_0$ and all other bits are zero.  Concatenate the
address, modular, and data bits in their order under $\pi$ as
$u_1,\ldots,u_N$.  At $c_{j-1}$, two cost-$C$ operators set $u_j$ to zero or
one and move to $c_j$.  At $c_N$, one cost-1 operator for each address
$d\in\{0,\ldots,B-1\}$ requires $a=d$ and $z_d=1$ and moves to $s_0$.
For every $0\leq\ell<B-1$, a cost-1 operator moves from $s_\ell$ to
$s_{\ell+1}$ without changing the other bits.  Finally, a cost-$C$ operator
applicable at $s_{B-1}$ sets $t=1$.
The goal is $t=1$.  Every solution therefore costs
\[
 \copt=NC+B+C.
\]
The task has $O(B)$ operators.  Binary control preconditions and address
tests give an explicit encoding of size $O(B\log B)$.

It remains to define the heuristic.  On the cyclic group $\mathbb Z_W$, let
\[
 \lambda(r)=
 \begin{cases}
   r, & 0\leq r<\values-1,\\
   \values-1, & \values-1\leq r<W.
 \end{cases}
\]
Every color class $\lambda^{-1}(v)$ has trivial stabilizer under cyclic
translation.  This is immediate for the singleton classes; the last class is
a nonempty proper cyclic interval, which no nonzero translation fixes.  On
every Boolean assignment, including assignments with an unused control code,
set
\[
 h(s)=
 \begin{cases}
   0, & s(t)=1,\\
   \lambda\!\left(\sum_{i=1}^B s(y_i)\bmod W\right), & s(t)=0.
 \end{cases}
\]
The heuristic has exactly the values $0,\ldots,\values-1$.  A generation
operator changes its value by at most $C$; the filter and persistent operators
preserve it; and the goal operator decreases it by at most $C$.  Hence $h$ is
consistent and, because it is zero at goals, admissible.

We next establish its exact width.  At a cut within the $y$-block, a prefix
affects the residual only through its Hamming-weight residue modulo $W$, so
there are at most $W$ residuals.  At every other cut there are no more.  For a
cut after $j$ modular bits with
\[
 W-1\leq j\leq B-W+1,
\]
both the prefix and suffix realize every residue in $\mathbb Z_W$.  If the
residuals induced by prefix residues $r$ and $r'$ were equal, then
$\lambda(r+x)=\lambda(r'+x)$ for every $x\in\mathbb Z_W$.  Each color class
would be invariant under translation by $r'-r$, so triviality of its
stabilizer gives $r=r'$.  The cut has $W$ distinct residuals, and therefore
$\width_\pi(h)=W$.

We now lower-bound heuristic effort.  Each persistent control value $s_\ell$
defines one exact layer
\[
 S_\ell=\{s_\ell\}\wedge[z_a=1]\wedge\neg t,
 \qquad 0\leq\ell<B,
\]
where $[z_a=1]$ denotes the multiplexer predicate.  The address, modular, and
data choices otherwise remain free.  Its cost is $NC+1+\ell$.  Every color
occurs in every such layer, and for every color $v$,
\[
 NC+1+\ell+v\leq NC+B+C=\copt.
\]
Lemma~\ref{lem-identity} therefore selects all $\values$ buckets in all $B$
persistent layers.

Fix one of these layers, a color $v$, and a cut after $j$ modular bits, where
\[
 W-1\leq j\leq B-W.
\]
For every address $d$ and prefix residue $r$, the bucket residual is
\[
 z_d\wedge\neg t\wedge
 \left[
 \lambda\!\left(r+\sum_{i=j+1}^B y_i\bmod W\right)=v
 \right].
\tag{1}\label{eq:mux-residual}
\]
These $BW$ residuals are pairwise distinct.  Different addresses are
separated by a data assignment, and different residues are separated by the
trivial cyclic stabilizer of $\lambda^{-1}(v)$.  Moreover, every residual in
\eqref{eq:mux-residual} depends on $y_{j+1}$.  Indeed, a nonempty proper color
class has an adjacent cyclic boundary, and the remaining $B-j-1\geq W-1$
bits can realize the residue at that boundary. Every displayed residual is
false when $t=1$, so no two are complements. In a reduced ordered BDD with
complemented edges, pairwise distinct, noncomplementary residuals that depend
on the next variable induce distinct regular nodes labeled by that variable.
Hence the reduced BDD for this bucket has at
least $BW$ nodes at each of the
$B-2W+2$ indicated modular levels.  Summing over colors and persistent layers
gives
\[
 \effort(\task,h)
 \geq \values\,B\,(BW)(B-2W+2)
 \geq \tfrac12\values WB^3,
\tag{2}\label{eq:joint-lower-effort}
\]
where the last inequality uses $B\geq4W$.

Finally, blind effort is only quadratic.  At generation control value $c_j$,
the exact layer fixes the control code, the $N-j$ not-yet-chosen bits, and
$t=0$; its BDD has $q+N-j+1$ nodes.  At a persistent control value, the
ordered multiplexer BDD consists of a full $B$-leaf address tree, one data
node per leaf, the shared $t$-node, and the control prefix, for $q+2B$ nodes.
Thus
\[
\begin{aligned}
 \effort(\task,\hblind)
 &\leq \sum_{j=0}^{N}(q+N-j+1)+B(q+2B)\\
 &=O(B^2).
\end{aligned}
\tag{3}\label{eq:joint-blind-effort}
\]
For the explicit constant, $B\geq8$ gives $m\leq B/2$, $q\leq B$,
$N+1\leq3B$, and $q+N+1\leq4B$.  The right-hand side of
\eqref{eq:joint-blind-effort} is therefore at most $15B^2$, whereas
\eqref{eq:joint-lower-effort} is at least $\values WB^3/2$.  Moreover,
$n=q+m+2B+1\leq4B$.  The ratio is consequently at least
$\values WB/30\geq\values Wn/120$.  The heuristic itself has an $O(BW)$
ordered ADD, so the entire construction is polynomial-size.
\end{proof}

For each fixed power-of-two $B$, the construction permits every pair
$2\leq\values\leq W\leq B/4$; varying $B$ changes
$n=2B+O(\log B)$. It therefore establishes joint worst-case necessity of all
three factors in Corollary~\ref{cor-effort}, rather than only necessity along
a tied diagonal. Its repeated multiplexer layers are constructed, so the theorem
is not a typical-case prediction.

\section{Width of the Known Exponential Pathology}

For completeness, the family $\task_n$ has binary variables
$v_1,\dots,v_{2n}$ and $x_0,\dots,x_{2n+1}$. Initially only $x_0$ is
true. For $i\in\{1,\ldots,2n\}$, operators $o_i$ and $\bar o_i$, whose precondition is
$x_{i-1}\wedge\neg x_i$, set $x_i$ true while setting $v_i$ true or
false, respectively. Once $x_0,\dots,x_{2n}$ are true, a goal operator
$g_i$, for $i\in\{1,\ldots,n\}$, is applicable when
$v_i\wedge v_{n+i}$ holds and achieves $x_{2n+1}$. The goal is
$x_{2n+1}$, and all chain and goal operators have unit cost. The order is
$\pi_n=x_0,\dots,x_{2n+1},v_1,\dots,v_{2n}$.

\begin{theorem}[width lower bound]
\label{thm-lb}
For the tasks $\task_n$ and orders $\pi_n$ of
\citet{speck-et-al-icaps2020},
$\width_{\pi_n}(\hstar) \geq 2^{n}$.
\end{theorem}

\begin{proof}
We exhibit $2^n$ prefixes with pairwise distinct \hstar-cofactors. For
$A \subseteq \{1, \dots, n\}$ let $\rho_A$ be the prefix that assigns
the $x$-variables the encoding of chain position $2n$, i.e.,
$x_0, \dots, x_{2n}$ true and $x_{2n+1}$ false, and assigns $v_i = 1$
iff $i \in A$ for $i \in \{1, \dots, n\}$. All $\rho_A$ fix the same
variables $x_0, \dots, x_{2n+1}, v_1, \dots, v_n$, so their cofactors
lie in $\sub{m}{\hstar}$ for the same level $m = (2n + 2) + n$. Let
$A \neq A'$ and pick without loss of generality
$i \in A \setminus A'$. Define the suffix $\sigma$ over
$v_{n+1}, \dots, v_{2n}$ by $v_{n+i} = 1$ and $v_{n+j} = 0$ for
$j \neq i$. The state $\rho_A \sigma$ satisfies
$v_i \wedge v_{n+i}$, so a goal operator is applicable and
$\hstar(\rho_A \sigma) = 1$. The state $\rho_{A'} \sigma$ satisfies
$v_j \wedge v_{n+j}$ for no $j$: for $j = i$ because $v_i = 0$ under
$\rho_{A'}$, and for $j \neq i$ because $v_{n+j} = 0$ under $\sigma$.
No other operator is applicable in either state, since every $o_i$ and
$\bar o_i$ requires $\neg x_i$ and $x_1, \dots, x_{2n}$ are all true.
Hence $\rho_{A'} \sigma$ is a dead
end and $\hstar(\rho_{A'} \sigma) = \infty \neq 1 =
\hstar(\rho_A \sigma)$, so
$\hstar|_{\rho_A} \neq \hstar|_{\rho_{A'}}$, and
$|\sub{m}{\hstar}| \geq 2^{n}$. Since the argument evaluates \hstar\
only on states, it applies to every total extension of \hstar\ to
the full cube $\{0,1\}^{4n+2}$ (Remark~\ref{rem-encoding}).
\end{proof}

\section{Width Bounds for Heuristic Families}

Let a SAS$^+$ task have variables $\vars=\{v_1,\dots,v_m\}$, let
$d=\max_v|D_v|$, and use a variable-contiguous Boolean order $\pi$.
An integer potential assigns $P(v,w)\in\mathbb Z$ to each fact, defines
$p(s)=\sum_{v\in\vars}P(v,s(v))$, and exposes the rectified heuristic
$\hpot(s)=\max(0,p(s))$.

\subsection{Integer Potentials}

\begin{proposition}
\label{prop-pot}
Let $p$ have integer potentials with $|P(v,w)|\leq M$ for all facts,
extended to non-state assignments by the same sum over the bit
encoding's induced table, with table values on invalid bit codes also
in $[-M,M]$, e.g., $0$, and let $\pi$ be variable-contiguous. Then
\[
\width_\pi(\hpot)\leq\width_\pi(p)\leq d(2mM+1)
\qquad\text{and}\qquad
|\hrange(\hpot)|\leq mM+1.
\]
\end{proposition}

\begin{proof}
Consider a prefix $\rho$ that fixes the variables
$v_1,\dots,v_j$ completely and the first
$b<\lceil\log_2d\rceil$ bits of $v_{j+1}$. The cofactor $p|_\rho$ is
determined by the accumulated sum
$\sum_{j'\leq j}P(v_{j'},\rho(v_{j'}))$, an integer in $[-mM,mM]$,
and by the assignment to the $b$ read bits of $v_{j+1}$. There are at
most $2mM+1$ sums and at most $2^b\leq d$ bit prefixes, so
$\width_\pi(p)\leq d(2mM+1)$. The raw total lies in $[-mM,mM]$;
rectification maps it to $\{0,\dots,mM\}$ and, as a terminal mapping,
cannot create cofactors.
\end{proof}

\begin{corollary}
\label{cor-pot}
For rectified consistent integer potential heuristics with magnitudes at
most $M$,
\[
\effort(\task,\hpot)
 \leq 2d(mM+1)(2mM+1)n\cdot\effort(\task,\hblind),
\]
a factor polynomial in the task size and the numeric magnitude $M$.
\end{corollary}

\begin{proof}
Proposition~\ref{prop-pot} gives
$W\leq d(2mM+1)$ and $\values\leq mM+1$; substitute both bounds in
Corollary~\ref{cor-effort}.
\end{proof}

\subsection{Pattern Databases}

\begin{proposition}
\label{prop-pdb}
Let $P\subseteq\vars$ be any pattern under a variable-contiguous order
$\pi$. Extend its table to invalid encodings by ignoring non-pattern
bits and mapping an invalid pattern-variable code to $0$. Let
$|\states^P|=\prod_{v\in P}|D_v|$. Then
\[
\width_\pi(h^P)\leq|\states^P|.
\]
\end{proposition}

\begin{proof}
Write $M=|\states^P|$ and fix a bit cut. Bits of variables outside $P$ are
irrelevant. Suppose first that the cut lies $b$ bits inside a pattern
variable of domain size $D$, and that $A$ valid assignments to earlier
pattern variables are possible. For
$b<\lceil\log_2D\rceil$, we have $2^b<D$. Valid prefixes therefore induce
at most $A2^b$ residuals. Prefixes containing an earlier invalid code all
share the constant-zero residual, so there are at most
$A2^b+1\leq AD\leq M$ residuals.

At a boundary between pattern variables, let $F$ be the product of the
unread pattern-domain sizes. If $F\geq2$, the same count is at most
$A+1\leq AF=M$. If $F=1$, the valid residuals are constants and invalid
codes map to $0$, which is already an attained PDB goal-distance terminal;
there are at most $M$ of them. This includes the cut after the full pattern.
Thus every cut has at most $M$ cofactors. An extension using a distinct
invalid-code sink has the alternative bound $M+1$.
\end{proof}

Since a PDB has at most $M$ finite values,
Corollary~\ref{cor-effort} gives
$\effort(\task,h^P)\leq2M^2n\effort(\task,\hblind)$ under the default-zero
extension. In particular, a raw PDB with at most $K$ abstract states is
automatically exact-width feasible under a width budget $K$.

\subsection{Linear Merge-and-Shrink}

A linear merge-and-shrink mapping is a cascade of tables
$\tau_1,\dots,\tau_m$, where $\tau_j$ maps the previous intermediate
abstract state and the value of $v_j$ to the next intermediate state.
The proposition's size premise applies to every table output, including the
final abstraction; it is stronger than a convention that bounds only selected
post-shrink products.

\begin{proposition}
\label{prop-ms}
Let $h^{\alpha}$ be an M\&S heuristic built with a linear merge
strategy whose variable order agrees with the variable-contiguous
$\pi$, and suppose the valid output set after every cascade table, including
the final abstraction, has at most $N$ states. Extend each
table with a distinguished sink for invalid variable codes. Then
$\width_\pi(h^{\alpha}) \leq d \cdot (N+1)$.
\end{proposition}

\begin{proof}
For a prefix $\rho$ fixing $v_1, \dots, v_j$ and $b$ bits of
$v_{j+1}$, the cofactor $h^{\alpha}|_\rho$ is determined by the
intermediate abstract state $\tau_j(\cdots)$ reached after processing
$v_1, \dots, v_j$ through the cascading tables, of which there are at
most $N$, or the distinguished sink, together with the $b$-bit buffer,
at most $d$ cases: the
remaining computation applies the fixed tables
$\tau_{j+1}, \dots, \tau_m$ and the final distance table to the suffix.
Thus at every cut there are at most $d(N+1)$ distinct cofactors.
\end{proof}

\section{Additional Related-Work Detail}
\label{sec:supp-related}

Heuristic symbolic search has long exposed a tension between information and
representation. \bddastar\ partitions a frontier by absolute heuristic value
\citep{edelkamp-reffel-ki1998}; SetA\ensuremath{^{*}} and \ghseta\ move
heuristic changes into transition-relation partitions
\citep{jensen-et-al-aij2008}; and ADDA\ensuremath{^{*}} represents values
algebraically \citep{hansen-et-al-sara2002}. The exponential separation of
\citet{speck-et-al-icaps2020} shows that even \hstar\ can be harmful under the
BDD-node effort measure.
The classical ADD representation already relates one multi-terminal diagram
to a forest of Boolean diagrams, one for each value
\citep{bahar-et-al-iccad1993}.
Torralba's terminal-substitution bound
\citep[Proposition~2.1]{torralba-phd2015} yields the coarser $E\leq kD$
certificate when applied to the masked ADD.
\citet{ciardo-miner-jva2023} explicitly compare an MTBDD with the corresponding
shared per-value BDD forest; its unique-node size differs from the rootwise sum
$E$ used here.
Reachable-terminal sets of individual MTBDD nodes are also used by
\citet{duret-lutz-et-al-ciaa2025}.
Terminal incidence refines this charge node by node: for each inner node, it
retains exactly which active value terminals remain reachable.
We do not claim the forest relation, per-value substitution or reachable-
terminal sets as new; to our knowledge, the summed node-local aggregate and
its $E\leq I$ charging bound have not previously been stated for rootwise-
summed value BDDs.
The legacy cofactor analysis gives a sufficient parameterized
representation-effort certificate for product-at-evaluation forward search,
and its exact-width selector operationalizes that condition.
The present analysis places those cofactor quantities above terminal
incidence in the fixed-frontier hierarchy; neither selector's ranking score
nor runtime follows from that hierarchy.

PDB construction and symbolic PDB use are established techniques
\citep{culberson-schaeffer-compint1998,edelkamp-ecp2001}. In particular,
automatic CEGAR pattern generation is due to
\citet{rovner-et-al-icaps2019}, and compiling PDBs and M\&S heuristics into
BDD value sets predates this work \citep{edelkamp-et-al-ecai2012}.
Entry compression merges PDB locations while retaining a lower bound
\citep{felner-et-al-jair2007}; value compression keeps the locations but maps
several values to one stored value \citep{sturtevant-et-al-aaai2017}. A
uniform cap is a special case of the latter idea.
We do not claim value coarsening as new.
The legacy cap analysis proves cutwise contraction for its residual-width
certificate; Proposition~\ref{prop:supp-incidence-contraction} strengthens
this statement to terminal incidence while preserving the explicit exception
for exact partition effort.
Relaxed BDD heuristics also use a width parameter to control a diagram over
action choices for delete-free planning \citep{castro-et-al-icaps2019}. That
construction width is distinct from the residual width of the total
state-to-value heuristic ADD that partitions search frontiers here.
\citet{torralba-phd2015} studied polynomial BDD representations of linear M\&S
heuristics, while \citet{helmert-et-al-icaps2015} made their cascading
factored mappings explicit. We do not claim the empty, BDD-prefix,
goal/causal-prefix, goal-fill, or CEGAR generators as new heuristic
algorithms.
The developmental selector studies used a fixed, provenance-preserving
generator and deduplication recipe, verified raw-pool identity where they made
mechanism comparisons, measured every resulting ADD in the search order and
rejected candidates that exceeded the declared width budget.

Potential heuristics \citep{pommerening-et-al-aaai2015} and their integration
into symbolic search \citep{fiser-et-al-aaai2022,fiser-et-al-aij2024} provide
another compact family. Corollary~\ref{cor-pot} bounds rectified integer
potential level sets, not the cost-and-delta transition partitions used by
\ghseta. Likewise, Proposition~\ref{prop-ms} gives the bound $d(N+1)$ only
when the linear merge order agrees with the search variable order and every
cascade output, including the final abstraction, has at most $N$ states. A causal-graph construction with
\texttt{align\_merge\_order=false} is not certified by that formula, even if
its width is measured exactly afterward.

Finally, \citet{speck-helmert-ecai2025} compare symbolic and explicit blind
search through the representation of transition relations and goal formulas.
Our comparison is complementary: it bounds heuristic over blind symbolic
representation effort. Variable-ordering studies
\citep{kissmann-hoffmann-jair2014} are directly relevant because width is
order-dependent. Symbolic perimeter abstractions
\citep{torralba-et-al-ijcai2016a,torralba-et-al-aij2018} and pruning-only
search both delay or restrict heuristic work, but use different mechanisms.
Theorem~\ref{thm-bucket} applies to a fixed slice in either search direction;
a cumulative bidirectional guarantee accounting for changing incumbents,
meeting points, and direction choices remains open.
